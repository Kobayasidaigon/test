# FIT-EASY 法人契約 案内動画（モーショングラフィックス版）

スライドを切り替える形式をやめて、カットなしの 1 本の流れでつないだ動画です。
1920×1080 / 30fps / 40 秒 / 音声なし / H.264（BT.709）。最後は暗転して冒頭の黒につながるので、ループ再生しても継ぎ目が出ません。

- 完成ファイル: `out/fit-easy-corporate.mp4`
- 文言は元動画と同じです。QR は元動画のものを読み取り、同じ URL（`https://shops.fiteasy.jp/corporate-membership`）でベクターとして作り直しています。

## 流れ

| 時間 | 内容 | 動き |
| --- | --- | --- |
| 0–9s | 会社員のみなさまへ「そのジム通い、会社の福利厚生にできるかも。」 | リングが描かれながら回り、1 行目を中央に大きく出してから左上へリフレーム。文字は 1 文字ずつ下から立ち上がる |
| 9s | つなぎ | 文字が上に抜け、リングが閉じてライムで塗りつぶし → 同じ中心から円形に次の画面が開く |
| 9–20s | しくみは、かんたん 3 ステップ | カメラが STEP 1→2→3 を順に追いかけ、最後に引いて全体を見せる。契約書にサイン→判子、スマホにパスワード入力→チェック、時計がぐるぐる回る |
| 20s | つなぎ | 黒い STEP 3 カードにカメラが突っ込み、そのまま次の画面の背景になる |
| 20–28s | 社長・総務の方へ「社員の健康寿命を、会社で支える。」 | 心電図モニターが流れ、鼓動に合わせて「健康寿命」が脈打つ |
| 28s | つなぎ | ライムの波が下から満ちる |
| 28–40s | 「このQRを見せてください。」 | 吹き出しがタイプ表示、QR カードが回転して登場、スキャン枠とスキャンライン、QR から波紋が広がる（QR 自体は読み取りやすいよう静止） |
| 39–40s | 終わり | QR の位置から暗転 → 冒頭へ |

## 書き出し方

```bash
npm install
node scripts/render.mjs                    # out/fit-easy-corporate.mp4 を書き出し（4 並列で 7 分ほど）
node scripts/render.mjs --stills 3,17,33   # 指定秒の静止画を out/stills/ に（確認用、数秒）
```

Playwright（Chromium）と ffmpeg が必要です。ブラウザで `src/index.html?play` を開くとリアルタイムで再生できます（`?play=20` で 20 秒目から）。

書き出しは 1 フレームごとにブラウザで描画し、シャッターが開いている間を複数回撮って平均することでモーションブラーを付けています（通常 8 枚、速い場面は 20 枚）。

## 直すときの場所

- 文言・レイアウト: `src/index.html`、`src/style.css`
- 動きとタイミング: `src/main.js`（秒数を直接書いています。各シーンの見出しコメント参照）
- 色: `src/style.css` 冒頭の `:root`（濃紺 `#14171e` / ライム `#8dc01d` / オフホワイト `#f4f5eb`）
- QR の URL: `scripts/gen-qr.mjs` を書き換えて `node scripts/gen-qr.mjs`

フォントは Noto Sans JP と Barlow Condensed（どちらも SIL Open Font License）、アニメーションは GSAP を使っています。
