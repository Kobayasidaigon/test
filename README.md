# 備品トラブル対応台帳

備品・設備が壊れた／盗まれた／なくなった時に、対応状況を一覧で管理するための Web 台帳です。

## web/index.html

Claude の Artifact として公開しているページ本体です（`<html>`/`<body>` を含まない形式）。
同じページを開いた人が同じ一覧を見て更新できます。

### 画面

- 上部のタイルに、未対応・対応中・保留・期限超過・今月の受付・完了 の件数を表示。
  タイルをクリックすると、その案件だけに絞り込める
- 一覧は期限が近い順。期限超過は行の左端が赤、期限3日前は橙になる
- 完了した案件は初期状態では非表示（「完了も表示」で表示）
- 検索、区分・担当者での絞り込み、並び替えに対応
- 案件をクリックすると詳細パネルが開き、対応状況の変更・各項目の編集・対応履歴の追記ができる
- 「＋ 新規登録」で管理No.（年-連番）を自動採番
- 「CSV書き出し」で Excel に貼り付けられる CSV を保存
- 「担当者リスト」で対応担当者の候補を編集
- スマホ表示とダークモードに対応

### 管理項目

管理No.、対応状況、区分、対象物（品名）、発生場所、報告者、状況・詳細、
優先度、対応担当者、受付日、発生日、対応期限、完了日、経過日数（自動）、期限判定（自動）、
備考、対応履歴。

ジム（フィットネス施設）での利用を前提に、項目名・入力例・記入例をあわせています。

### 保存先

共有データベースに保存します。共有保存が使えない環境で開いた場合は、
そのブラウザ内にのみ保存するモードへ自動で切り替わり、画面上部にその旨を表示します。
