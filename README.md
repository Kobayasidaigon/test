## prototypes/car-keep-game

「この車、あと何年乗るのが一番得？」のゲーム版プロトタイプ。ブラウザで `prototypes/car-keep-game/index.html` を開くと動きます（ビルド不要・1ファイル）。

- 車のタイプ・年式・走行距離・年間走行距離・乗り換え先を入れて出発すると、車が1年ずつ道を走る
- 車検ゲート、13年超え・18年超えの増税、10万kmの壁が道の上のイベントとして出てくる
- 「得の推移」グラフが伸びていき、好きな年に「売る」を押すと、一番得な年と比べて採点（S〜D）
- 計算モデルは `<script id="model">` に独立させてあり、画面なしでもテストできる
- 税額・重量税・自賠責は公的な額、買取価格の下がり方や修理費の増え方はデモ用の想定値（ページ内「計算の前提と出典」に記載）
