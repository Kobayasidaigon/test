## 対応管理表.xlsx

備品・設備が壊れた／盗まれた／なくなった時に、対応状況を一覧で管理するための Excel 台帳です。

| シート | 内容 |
|---|---|
| 対応管理表 | 本体。1件1行で登録。区分・対応状況などはプルダウン、対応状況に応じて自動で色分け、期限超過・期限間近を自動判定 |
| 集計 | 対応状況別・区分別の件数、期限超過件数、今月の受付件数、費用合計を自動集計 |
| マスタ | プルダウンの選択肢（区分・対応状況・優先度・警察届出・担当者）。担当者名はここで編集 |
| 使い方 | 記入の流れ、色の意味、各列の説明 |

記入例が3行入っています（備考に「※記入例」）。運用開始前に削除してください。

## Web 版（web/index.html）

同じ台帳をブラウザで使える Web ページ版です。Claude の Artifact として公開しており、
公開ページでは同じ組織のメンバーと一覧を共有できます（共有保存が使えない環境では、そのブラウザ内にのみ保存されます）。

- 集計タイル（未対応・対応中・保留・期限超過・今月の受付・完了）をクリックすると、その案件だけに絞り込み
- 案件をクリックすると詳細パネルが開き、対応状況の変更・各項目の編集・対応履歴の追記ができる
- 「＋ 新規登録」で管理No.（年-連番）を自動採番
- 「CSV書き出し」で Excel に貼り付けられる CSV を保存
- 「担当者リスト」で対応担当者の候補を編集

`web/index.html` は Artifact 用のページ本体（`<html>`/`<body>` を含まない形式）です。
