# 備品トラブル対応台帳

備品・設備が壊れた／盗まれた／なくなった時に、対応状況を一覧で管理するための台帳です。

## 対応管理表.xlsx（本体）

Google スプレッドシートで使うことを前提に作っています。Excel でもそのまま使えます。
Google ドライブにアップロードし、右クリック ＞ アプリで開く ＞ Google スプレッドシート
で開いたあと、ファイル ＞ Google スプレッドシートとして保存 を実行してください。

| シート | 内容 |
|---|---|
| 対応管理表 | 本体。1件1行。1行目に未完了・期限超過・期限間近・担当未定の件数と、次に使う管理No.を自動表示 |
| 集計 | 対応状況別・区分別の件数、期限超過件数、今月の受付件数、費用合計 |
| マスタ | プルダウンの選択肢（区分・対応状況・優先度・警察届出・担当者） |
| 使い方 | 取り込み手順、画面の見かた、記入の流れ、各列の説明、複数人で使うときのコツ |

見やすさのための設計:

- 1行目のサマリーは、期限超過が1件でもあると赤字になる
- 1〜2行目と、管理No.・対応状況・対象物の3列を固定。右にスクロールしても行を見失わない
- 左から10列（管理No.〜経過日数）で、日々の確認に必要な情報がそろう
- 行の高さを固定し、文字を折り返さない。1行＝1件で高さが揃い、一覧性が高い
- 「対応内容・経過」は最新を一番上に書く運用。一覧には最新の1行だけが表示される
- 対応状況・期限判定・優先度・期限超過の行は条件付き書式で自動的に色が付く
  （適用範囲は列ごとに登録。Google スプレッドシートは最初に一致したルールだけを適用するため）

記入例が3行入っています（備考に「※記入例」）。運用開始前に削除してください。
