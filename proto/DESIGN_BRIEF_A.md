## やること
1. **審査の指摘を直す。** `src/variants/a/REVIEW_ROUND1.json` に、最初の版への2人の審査（遊び心と見た目／わかりやすさと誠実さ）がある。重大度「高」はすべて、「中」はできるだけ直す。特に:
   - 上の金額は期間の平均なので、`comparison.perYearLabel`（例「1年あたり（5年の平均）」）を必ず添える。項目カードの「1年目」の数字と混同させない。
   - 確認中しかない比較で「ほぼ0円」と言い切らない。`comparison.status`（ok／partial／unknown）を見て、unknown なら金額の箱を「確認中」の表示にする。表情の一言は `moodText(comparison)` を使う（MOOD_TEXT を直接引かない）。
   - 上の金額の箱に、何が入っていないか（`comparison.excluded`）を添える。
   - プラスの結果で、家族と貯金箱がはねる・コインが飛ぶ動きが本当に再生されること（AnimatePresence initial={false} の問題）。
   - 桜島の絵柄が有名キャラクターの頭の形に見えないように描き直す。
   - ガチャの演出で、カプセルが筐体から出てくるように見せる（空から落ちてこない）。
   - 家族の問いで、年齢つまみ・「保育園に通う」が下の帯に隠れない。
   - 3つの区が同じはんこになる問題（区ごとに見分けがつくように）。名物の「おまけ」をもっと楽しく。1440px の結果が白いカードの縦並びにならないように。
2. **全国の街を選べるようにする。** 今の街も、候補の街も、全国1,741市区町村から選べる。
3. **「えらんでくらべる」モードを足す。** ガチャ（おまかせ）とは別に、行きたい街を2〜5個選んで、そこでの結果を並べて見られるようにする。
4. **案Aの世界観で作る。** 全国の街探しも、えらんでくらべるも、カプセルトイの筐体・カプセル・札・つまみ・棚・スタンプ帳の文法で作る（例: 行きたい街の名前をカプセルに書いて筐体に入れる → ハンドルを回すと、入れたカプセルが順に出てくる → 「くらべ棚」に並ぶ）。

## 共通データの新しい使い方（@/shared。編集はしない）
- `ALL_CITIES` … 全国1,741市区町村の `City`。`city.level` が `detailed`（市の制度まで調べた街。13）、`pref`（都道府県の制度だけ分かる街。東京都・埼玉県の市区町村など）、`basic`（国の制度だけ。くわしいデータは準備中）。`DATA_LEVEL_TEXT[level]` に説明文。
  - `city.kana`、`city.lat`/`city.lng`（役所の位置）、`city.url`（公式サイト）、`city.phrase`（街のキャッチフレーズ）もある。
- `CITIES` … くわしい街（detailed）。2026年11月1日に20市を足して33件（`src/shared/detailed20.ts`）。全国データを合わせたあとの City（ALL_CITIES と同じもの）。
- `cityById(id)` … 短いid（'adachi'）でも、地方公共団体コード（'131211'）でも引ける。
- `PREFS` … 47都道府県（北から順）。`citiesInPref(pref)` でその県の市区町村。
- `searchCities(query, limit)` … 名前・読みがな（ひらがな・カタカナどちらでも）で探す。
- `nearbyCities(fromId, km, limit)` … 今の街の近く（直線距離）。
- `rank(input, { pool, radiusKm, limit })` … おまかせの候補。`pool: 'featured'`（くわしい街だけ。既定）、`'nearby'`（近く。通勤・パートの人向け）、`'all'`（全国。リモート・自営の人向け）。並びは、段（全部わかる街と、確認中の項目があってもわかる分で年1万円以上得になる街 → 確認中の項目があり、わかる分では得にならない街 → わかる差が1つもない街）→ 毎年の差が大きい順 → 同じ額なら、全部わかる街・一度きりのお金がある街・くわしい街・今の街に近い順（calc.ts の sortTier と sortComparisons）。被災した街は入れない。一度きりのお金は額の大きさには足さない。
- `compareMany(input, ids)` … 選んだ街を、選んだ順のまま比べる。
- `Comparison` に増えたもの: `status`、`perYearLabel`、`excluded`、`care`（災害への配慮）、`distanceKm`。
- `moodText(comparison)` … 表情の一言（確認中・配慮も含めて決める）。
- `MUNI_SOURCE` … 市区町村の一覧の出典（Code for FUKUI「localgovjp」、CC0）。フッターなどに出典として書く。

## 守ること（追加）
- **データの細かさを正直に見せる。** くわしい街／県の制度だけ／準備中を、カプセルの見た目（色の濃さ・模様・札など）で区別し、言葉でも説明する。準備中の街で「ほぼ0円」と言わない。
- **災害への配慮。** `comparison.care` があるとき、その文を見せる。`care.level === 'hit'`（令和8年熊本地震で大きな被害を受けた街）では、順位づけ・悲しい表情・紙ふぶき・「損」の演出を出さず、公式の情報（care.sources）へのリンクを出す。
- **全国ワースト一覧は作らない。** 並べるのは得する順まで。順位の数字（1位・2位）より「いちばん上」「ほかの候補」のような言い方。
- 1,741件を一度に全部描かない（検索・県で絞る・近くの街・おすすめで選ばせる）。スマホで重くしない。
- 入力例（SAMPLE_INPUT）は草加市の家族。`?step=result` で、その結果へいきなり飛べること。加えて、えらんでくらべるの結果へ飛べる `?step=compare`（例: 足立区・市川市・川崎市・大田区・八王子市を選んだ状態）も用意する。
