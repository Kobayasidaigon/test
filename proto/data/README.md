## 全国の材料（2026年11月1日に取り込み）

`node scripts/gen-national.mjs` で、下のファイルから `src/shared/national.ts` を作り直す（手で編集しない）。`src/shared/data.ts` がそれを全国1,741市区町村の `City` に重ねる。くわしい街（33）は、その街の調べを先に使い、まだ調べていない項目（仮の値のまま・出典なし）だけを全国の材料で埋める。

取り込みの決まり（`scripts/gen-national.mjs` の先頭にも書いた）:
- 確かめていない項目は入れない（0円・「ない」にしない）。表にない街・項目は、画面で「確認中」「準備中」になる。
- 値には確からしさ（確認済・推定）・時点・出典を付ける。今年度（令和8年度・2026年）の情報でないものは、確認済でも「推定」に下げる。
- 県が「全市町村で実施」と書いている制度は、市町村ごとには確かめていないので「推定」まで。手挙げ（実施する市町村に県が補助）の制度は、実施市町村の一覧がある市町村だけ入れる。
- 民間のまとめだけが根拠の値は、今年度の記事でなければ入れない。中身を開けなかった公式ページ（検索結果に題名や概要が出ただけ）も、それだけでは根拠に数えない。
- 所得の条件があるか確かめていない無償化は、年収の目安（600万円。県の基準が分かる山梨県・秋田県は640万円）より下の年収帯だけを0円とし、目安にかかる年収帯と上の年収帯は「確認中」にする（どの年収でも0円とはしない）。画面では額を言わず「所得の条件は確認中」と書く。
- 「予定」（報道）としか分からない制度と、0〜2歳の第1子を含むと書かれていない制度は、第1子の0円に入れない。
- 今年度も続いているか分からない値（2024年度からの給食費の無償化など）は、計算に入れず「確認中」にして、メモに過去の値を書く。
- 画面に出るメモと出典の名前からは、調べた作業の言葉（要約・照合・収集・ファイル名など）を除き、「ページの概要による」「未確認」などの言い方にする（`gen-national.mjs` の PLAIN・LABEL_PLAIN）。
- 取り込みの件数と、入れなかった行の理由は、`node scripts/gen-national.mjs <出力.json>` で書き出せる。

### 待機児童 `waiting.csv`
- 全1,741市区町村の待機児童数（令和8年4月1日）。列は code, pref, name, waiting, as_of, source_label, source_url, confidence, note。
- 出典: こども家庭庁「保育所等関連状況取りまとめ（令和8年4月1日）」（参考）定員・申込者の状況（Excel）「申込者の状況」シートの「合計・待機児童」列 https://www.cfa.go.jp/policies/hoiku/torimatome/r8 （加工して作成）
- 利用条件: こども家庭庁の公共データ利用規約（第1.0版。政府標準利用規約と同じ考え方で、出典と加工したことを書けば使える）。
- 読み方の注意: 国の定義の待機児童（特定の園だけを希望している子・育休中などは数えない）。表には全市区町村が載っていて、0人も表の値。取りまとめ全体が暫定値で、熊本県内は令和8年熊本地震の影響で未確定（サイトでは熊本県内を「推定」にしている）。「0人」でも、希望の園に入れるとは限らない。サイトでは、お金の差とは別の「暮らしの目安」として出す。
- 表の名前の字のちがい: 高知県の檮原町は、こども家庭庁の表では「梼原町」。

### 中学校の給食費 `lunch-mext.csv`・`lunch-notes.json`
- 全1,741市区町村の中学校・小学校の給食費が無料か（全員／一部／なし／不明）。値ごとの確からしさ（jh_confidence・elem_confidence）・時点（as_of）・出典（「 | 」区切り）つき。分かったのは中学校で189市区町村（東京都62・大阪府43・青森県40・和歌山県30・20市調査など）。残り1,552は不明。
- 文部科学省は市区町村ごとの無償化の一覧を公表していない（令和5年9月1日現在の実態調査は集計だけ）。値は、東京都・青森県・和歌山県の発表、市区町村の案内、報道、まとめサイト（art-pi、2026年8月30日確認）など。まとめサイトの値は「推定」。
- 計算の月額: 文部科学省「学校給食実施状況等調査」令和7年度（2026年7月30日公表）の公立中学校の全国平均 月6,013円 https://www.mext.go.jp/content/20260730-mxt-kenshoku-000051287_03.pdf （政府標準利用規約〈第2.0版〉に準拠。加工して作成）
- 読み方の注意: 青森県（2024年10月から）・和歌山県（2024年12月の知事メッセージ）の69市町村は2026年度も同じか未確認なので、計算には入れず「確認中」にし、2024年度から無料になったことを note に書いた（2026年11月1日に検索で確かめ直したが、令和8年度の継続は見つからなかった）。「なし」は全員の無償化がないという意味で、第3子以降などの一部無償があるかは確かめていない。小学校は2026年4月から国の負担軽減（月5,200円×11か月が基準）が全国にあるので、サイトの計算には入れていない。
- 20市調査の流山市・調布市・神戸市は、`detailed20.ts` の照合で確かめきれず「確認中」にした値を優先し、このCSVの推定値は使っていない。

### 移住支援金 `iju-list.csv`・`iju-rules.json`
- 全1,741市区町村の、地方創生移住支援事業の実施（実施／一部地域／実施なし／対象外／未確認）と子どもの加算。`iju-rules.json` に要件（移る前の住所・申請の時期・5年住む意思・就業など・返す決まり）と額（世帯最大100万円・単身最大60万円・子1人最大100万円）。
- 出典: 内閣府 地方創生「移住支援金」 https://www.chisou.go.jp/sousei/ijyu_shienkin.html （政府標準利用規約〈第2.0版〉に準拠）、都道府県・市町村の案内（千葉県・沖縄県・兵庫県・島根県・和歌山県・鳥取県、札幌市・仙台市など。行ごとの出典）。
- 読み方の注意: 内閣府の令和8年度の実施市町村一覧（令和8年4月1日時点）は読めなかったので、値はすべて「推定」。分かったのは343市区町村（実施138・実施なし47・一部地域1・対象外157）。世帯の額が書かれていない街は国の上限（世帯100万円）を「最大」の額として出す。子どもの加算の額が分からない街（「最大100万円。市町村によって少ないことがある」。実施138のうち133）は、加算を額に足さず「＋子どもの加算（確認中）」と出し、確からしさを1つ下げる（国の上限を掛けた大きな額を出さない）。東京圏の条件不利地域で実施しているか分からない32市町村（東京11・埼玉15・神奈川6）は、23区から移る家族に「準備中」と出す（「ない」とは言わない）。実施なしの47は「実施なし（時点つき）」と出し、決まりの上の「対象外」とは言い分ける。対象外（東京圏の条件不利地域でない市区町村）は、決まりの上で移住先にならない街で、サイトでは今までどおり移住支援金の欄を出さない。

### 0〜2歳の保育料の制度 `muni-nursery-policies.json`・`pref-nursery-east.json`・`pref-nursery-west.json`
- `muni-nursery-policies.json`: 市区町村の0〜2歳の保育料の無償化（第1子から／所得の条件つき／一部の年齢だけ／第2子以降）の一覧（457行）。行ごとに、きょうだいの数え方・所得制限・開始・出典・確からしさ・時点。県の一覧（北海道・秋田県・福島県・青森県・鳥取県）、東京都の事業の実績（令和7年度。23区26市5町3村で実施）、県の説明（岩手・栃木・山梨・福井・山口・大分）、市区町村の案内、報道など。
- `pref-nursery-east.json`（北海道・東北・関東・中部の23都道県）・`pref-nursery-west.json`（近畿〜沖縄の24府県）: 都道府県の0〜2歳の保育料の制度。県のサイトはこの環境から開けず、値はすべて検索結果の要約による「推定」。
- サイトへの入れ方: 市区町村の一覧の行と、県が「全市町村で」と書いている鳥取県の第3子以降の制度を重ね、347市区町村に保育料の制度が入った。市区町村の一覧のうち入れなかったのは113行（民間のまとめだけが根拠で古いもの47、徳島県の第1子からの無償化〈県の説明で支援の中身が市町村ごとに違う手挙げの制度〉24、対象〈第1子からか第2子からか〉が未確認15、0〜2歳の第1子を含むと書かれていない13〈北海道12・群馬県嬬恋村〉、令和8年度からの「予定」（報道）だけ11〈青森県〉、民間のまとめと中身を開けなかった町のページだけ1〈熊本県美里町〉、一部の年齢だけの無償化で所得の条件があるか分からない1〈群馬県片品村〉、所得の条件の額が分からない1）。所得の条件があるか確かめていない行は、第1子0円58市町村（北海道20・青森県22・福島県15・群馬県みどり市）、2人目0円77市町村（岩手県33・山梨県27・北海道8など）で、目安の年収より上は「確認中」。山梨県の3人目（同じ世帯の子で数える分）にも同じ目安を付けた。県の制度で入れなかったのは、栃木・山梨（市区町村の一覧に同じ制度が入っている）、埼玉（`data.ts` で入れている）、富山（第3子の数え方が分からず国の基準と同じ計算になる）、鳥取の低所得の第2子（年収約360万円未満で、サイトの年収帯の途中に境目がある）。保育料の月額の表は、この材料にはない（月額の表があるのは、くわしい街の一部だけ）。
- 利用条件: 都道府県・市区町村のサイトはそれぞれの利用規約による（多くは政府標準利用規約に準拠）。制度の有無・対象・額という事実だけを使い、出典を行ごとに付け、加工して作成したことをサイトに書く。

### 子ども医療費 令和8年の版 `medical-r8-notes.json`
- 令和8年4月1日時点の調査は、2026年11月1日の時点では未公表（例年12月公表）。サイトは令和7年の版（`medical-r7.csv`）のまま。公表されたら、令和7年の版と同じ列の `medical-r8.csv` を作れば、`gen-national.mjs` が自動でそちらを使う（書式の違いと読み方の手順はこのメモにある）。
- 令和7年の版は今年度の値ではないので、所得制限がない街も確からしさを「推定」にしている（`data.ts` の nationalMedical。令和8年の版に替わると、所得制限がない街は「確認済」になる）。年齢の書き方が「就学前」か「◯歳年度末」でない行があると、生成は止まる。`site/public/about.html` の医療費の出典の文は手で書いているので、版が変わったら書き換える（生成のときに注意が出る）。
- くわしい街の医療費は、市の情報が「確認済」のときだけ市の情報を使い、それ以外は国の全国調査の値にした（相模原市は、前の「15歳まで（報道の見出し）」をやめ、国の調査の18歳・所得制限あり）。
