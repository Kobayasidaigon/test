# data/

- `localgovjp-utf8.csv` … 全国の地方公共団体（都道府県・市区町村・政令市の区）の一覧。名前、読みがな、緯度経度（役所の位置）、公式サイトURL、キャッチフレーズ、地方公共団体コード。
  - 出典: Code for FUKUI「localgovjp」 https://github.com/code4fukui/localgovjp （元データ: 国土地理院、地方公共団体情報システム機構）
  - ライセンス: CC0
  - 取得日: 2026年11月1日
- `scripts/gen-municipalities.mjs` で `src/shared/municipalities.ts` を作る（政令市の区は除き、1,741市区町村）。
- `medical-r7.csv` … 子ども医療費助成の市区町村別の実施状況（令和7年4月1日時点）。通院・入院の対象年齢、所得制限、一部自己負担。
  - 出典: こども家庭庁「こどもに係る医療費の助成についての調査（令和7年度）」別紙3 https://www.cfa.go.jp/policies/boshihoken/kodomoiryouhityousa-r7 （PDFから抜き出して作成）
  - 利用条件: こども家庭庁の公共データ利用規約（第1.0版）。出典を書き、加工したことを書く。
  - 注意: 公表資料では奈良県の29番の行が「17 安堵町」と重複して印字されている（本来は吉野町とみられる）。推測せず、吉野町は「確認中」にしている。
  - 取得日: 2026年11月1日
- `rent-r5.csv` … 市区町村別の借家の1か月当たり家賃の平均（家賃0円を含まない）。総数、居住室18.0〜23.9畳、24.0〜29.9畳。
  - 出典: 総務省統計局「令和5年住宅・土地統計調査」住宅及び世帯に関する基本集計 第111-3表（e-Stat）https://www.e-stat.go.jp/stat-search/file-download?statInfId=000040210044&fileKind=0 （加工して作成）
  - 利用条件: e-Stat の利用規約（政府標準利用規約に準拠）。出典を書き、加工したことを書く。国が作ったように見せない。
  - 注意: いま住んでいる世帯が払っている家賃の平均で、これから借りるときの募集家賃より低めに出やすい。人口の少ない町村は集計されていない。
  - 取得日: 2026年11月1日
