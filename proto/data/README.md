## 全国の材料（2026年11月1日に取り込み。給食・移住支援金・都道府県の保育料の制度は、同じ日に公式の資料で確かめ直した版）

`node scripts/gen-national.mjs` で、下のファイルから `src/shared/national.ts` を作り直す（手で編集しない）。`src/shared/data.ts` がそれを全国1,741市区町村の `City` に重ねる。くわしい街（33）は、その街の調べを先に使い、まだ調べていない項目（仮の値のまま・出典なし）だけを全国の材料で埋める。

取り込みの決まり（`scripts/gen-national.mjs` の先頭にも書いた）:
- 確かめていない項目は入れない（0円・「ない」にしない）。表にない街・項目は、画面で「確認中」「準備中」になる。
- 値には確からしさ（確認済・推定）・時点・出典を付ける。今年度（令和8年度・2026年）の情報でないものは、確認済でも「推定」に下げる。
- 県が「全市町村で実施」と書いている制度は、市町村ごとには確かめていないので「推定」まで。手挙げ（実施する市町村に県が補助）の制度は、実施市町村の一覧がある市町村だけ入れる。
- 民間のまとめだけが根拠の値は、今年度の記事でなければ入れない。中身を開けなかった公式ページ（検索結果に題名や概要が出ただけ）も、それだけでは根拠に数えない。
- 所得の条件があるか確かめていない無償化は、年収の目安（600万円。県の基準が分かる山梨県・秋田県は640万円）より下の年収帯だけを0円とし、目安にかかる年収帯と上の年収帯は「確認中」にする（どの年収でも0円とはしない）。画面では額を言わず「所得の条件は確認中」と書く。
- 「予定」（報道）としか分からない制度と、0〜2歳の第1子を含むと書かれていない制度は、第1子の0円に入れない。
- 今年度も続いているか分からない値（2024年度からの給食費の無償化など）は、計算に入れず「確認中」にして、メモに過去の値を書く。
- 画面に出るメモと出典の名前からは、調べた作業の言葉（要約・照合・収集・ファイル名など）を除き、「ページの概要による」「未確認」などの言い方にする（`gen-national.mjs` の PLAIN・LABEL_PLAIN）。材料のメモの頭の【確認済】【推定】は確からしさの写しなので、画面には出さない。
- 県の制度は、実施している市町村のコードがあり、サイトの計算で表せて、国の基準より有利になるものだけ入れる（`gen-national.mjs` の PREF_IMPORT。入れない制度は PREF_SKIP と理由）。県の今年度の一覧（市町村ごとの欄）や交付決定の一覧で実施が分かる制度は「確認済」まで、県が「全市町村で」と書いているだけの制度は「推定」まで。
- 1つの街に制度が重なるときは、計算に効いている規則で確からしさを決める（ほかの規則と同じ結果になる、弱い規則は数えない）。
- くわしい街でも、全国の材料が公式のページで確かめた値（確認済）で、街の調べが確認済でない項目（給食・移住支援金）は、全国の材料を使う（`data.ts`）。
- 移住支援金の受付が今年度は予算の上限で終わった・止まった街は、額を出しつつ説明にそう書き、確からしさを1つ下げる（`calc.ts`）。
- 取り込みの件数と、入れなかった行の理由は、`node scripts/gen-national.mjs <出力.json>` で書き出せる。
