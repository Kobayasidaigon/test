# 保育料の表を集めるための道具

0〜2歳の保育料は市区町村ごとに表が違い、毎年変わる。全国の表を集め直すときに使う。

1. `order.py` … 住民基本台帳人口（総務省「住民基本台帳に基づく人口、人口動態及び世帯数」の市区町村別の表）を `data/localgovjp-utf8.csv` に付けて、人口の多い順の一覧（JSON）を作る。
   - `python3 -I order.py <人口のExcel> ../../data/localgovjp-utf8.csv <出力.json>`（政令市の区は、あとで `src/shared/municipalities.ts` の1,741市区町村で絞る）
2. `crawl.py` … 各市区町村の公式サイトを、子育て → 保育 → 保育料 の順にたどり、保育料の表らしい文書（PDF・Excel・ページ）の候補を集めて文字にする。
   - `python3 -I crawl.py <人口順の一覧.json> <開始> <終わり> <出力フォルダ> [並列数]`
   - 1つのサイトには0.4秒あけて1つずつアクセスし、robots.txt（200 の文字のファイルのとき）に従う。1市区町村あたり最大90ページ・8文書。
3. 候補の文書から表を読み取るのは人（または Claude）の仕事。結果は `data/fees/raw/<地方公共団体コード>.json` に、出典・年度・確からしさと一緒に置く（形は `data/README.md`）。
4. `crawl_lunch.py` … `crawl.py` の給食版。学校給食費（とくに中学校の無償化）のページ・文書の候補を集める。使い方は `crawl.py` と同じ。
