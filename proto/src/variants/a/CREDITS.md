# 案A「カプセルトイ」で使った 21st の部品

どれも、そのまま貼らずに、この案の世界観（ガチャの筐体・墨色の太線・ぼかさない影・トマト赤／卵黄／ソーダのミント）に合わせて作り変えています。

| 部品 | 作者 | URL | どこで使ったか | どう変えたか |
| --- | --- | --- | --- | --- |
| Kokonut UI Detent Dial | kokonutd（@dorianbaffier / kokonutUI, MIT License） | https://21st.dev/@kokonutd/components/kokonut-detent-dial | `dial.tsx`（子どもの年齢ダイヤル、期間のつまみ）、`handle.tsx`（ガチャのハンドル） | 回す計算（角度の折り返し・ノッチに吸い付く力・はじくと惰性・端で行き過ぎて戻る）、キーボード／ホイール、数字が転がる表示はほぼそのまま。回せる角度と始まりの角度を変えられるようにし、まわりに押せる札（1年／5年／18歳まで）を置けるようにした。見た目を卵黄色のつまみ＋墨の太線＋ふちのギザギザに。赤い目印はふちの帯の中だけに収め（窓の文字に重ねない）、読み上げの名前（例: 1人目の子の年齢）を外から渡せるようにした。ハンドルは同じ角度の計算を使い、時計回りにしか進まないラチェット（1/4回転ごとにカチッ、1周で決定、タップでも回る）に作り直した。影は回らない台に付けた。「回してね」の矢印は、ハンドルの左上に金属の輪にそった黄色い弧で描き直した。MIT の著作権表示は `dial.tsx` の先頭に残した。 |
| Number Flow | educalvolpz (Eduardo Calvo) | https://21st.dev/@educalvolpz/components/number-flow | `stepper.tsx`（大人・子どもの人数） | 「増えたら上へ、減ったら下へ数字が転がる」考え方を借り、CSS クラスの付け外しを motion の AnimatePresence で書き直した。3けたの箱をやめ、筐体の小さな数字窓（墨の窓に黄色の数字）1つに。日本語のラベルと読み上げを足した。 |
| Stamp（Awards variant="stamp"） | designali-in (Ali Imam) | https://21st.dev/@designali-in/components/stamp | `stamp.tsx`（ご当地はんこ・スタンプ帳・くらべ表の見出し） | 弧にそって文字を置く textPath の考え方を使い、上に「都道府県・街」、下に「住む街ガチャ・年月」。ギザギザの切手ふちと星アイコンをやめ、駅スタンプ風の二重の枠にした。枠の形で街の種類を分けた（市は丸、区は角丸の四角、町と村は八角形）。真ん中は、その街だけの名物の手描きの絵（せんべい・鉄瓶・梨・工場・ロケット・たこ焼き・包丁・とうもろこし・桜島）。県全体で同じ名物しかない街や、まだ名物を調べていない全国の街は、街の名前の字（足立・北・大田・八王子…）を置いた。インクは街ごとに色を変え、かすれ（feTurbulence と点の抜け）を足した。 |
| Confetti | motiondotdev（Motion 公式の例） | https://21st.dev/@motiondotdev/components/motion-confetti | `confetti.tsx`（カプセルが開いたとき。毎年の差がプラスのときだけ） | 粒の動きを前もってキーフレームに計算して流す仕組みはそのまま。ボタンを外して親から1回はじける形にし、粒をカプセルの半分・コイン・きらりに、色をこの案のパレットに変えた。動きを減らす設定と、被災した街では出さない。 |
| Segmented Control | balick | https://21st.dev/@balick/components/segmented-control | `tags.tsx`（働き方・保育園に通うか の札） | ラジオグループのふるまい（矢印キー・Home/End、選んだものだけ Tab で止まる）と、しるしが layoutId ですべる考え方を借りた。横一列のピルをやめ、ひもで吊るした札の格子に。選ぶと札がゆれて赤い丸のしるしが付く。札に絵（icon）と、選んだときの地の色（tint）を付けられるようにした。小さい札は字を折り返さず、札の最小の幅（minCol）より細くなる画面では縦に並べる。 |
| Combobox | halaska-studio | https://21st.dev/@halaska-studio/components/combobox | `towns.tsx`（全国の街さがし：今の街・行きたい街） | 入力欄にフォーカスを置いたまま aria-activedescendant で候補を指し、↓↑で動かし、Enter で決め、Esc で閉じる流れと、マウスを乗せると指す候補が動くところを借りた（依存ライブラリなし）。ポップアップの中にあった入力欄を外に出し、いつも見えている「カプセルに名前を書く」欄（role="combobox"）にした。候補は全国1,741の市区町村から名前・読みがなで探し（@/shared の searchCities）、行にデータのくわしさが分かるカプセルと札、今の街からの距離を付けた。見つかった件数を読み上げる。20件で切れたときや見つからないときは、県の名前・読み（ほっかいどう など）から「地方と県からさがす」の一覧を開くボタンを出す。デザイン用のトークン、すりガラス、紫のアクセントは使っていない。 |

探したが使わなかったもの（参考にしただけ）: Vending Machine（aadilghani1。ボタンで商品が落ちる流れ）、lever-switch（theutkarshmail）、Kokonut UI Pull Cord（kokonutd）。2回目に探したもの: 日本地図（見つからなかったので、地方→都道府県→市区町村とたどる棚を自分で作った）、Combobox（uvain／cmdk が要るので使わず）、比較表（TanStack Table が要るので使わず、くらべ棚の表は自分で作った）。
