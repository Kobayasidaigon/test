【この名前を使うときのベストな形】
・正式名とロゴは漢字の「住む街ガチャ」。ひらがなの「すむまちガチャ」は、移住マッチングの「スムマチ」とそっくりになるので使わない。

## ドメインの選び方

【.com と .jp】
・.jp（○○○.jp の形の汎用JP）は、日本国内に住所がある個人・組織だけが登録できる（Gandi https://www.gandi.net/ja/domain/tld/jp 、Weblio）。日本の家族向けのサイトだと一目で分かる。今回出てきた同じ分野の既存サイトも、machikurabe.jp、suumo.jp、smocca.jp、hikkoshizamurai.jp と .jp が多い。だれでも取れる .com より、量産サイトに使われにくい（推定）。
・.com は世界共通で、.jp より安い。打ち慣れている人も多い。
・co.jp などは会社などの組織向けで、個人のサイトでは取れない。
・JPRS の資料（2017年の規則 https://jprs.jp/doc/rule/archive/dom-data-handling.20170530.html ）には、個人が .jp を登録すると、その個人の情報が WHOIS（ドメインの持ち主を調べる仕組み）で公開・開示されるとある。今の表示のしかたは未確認。登録サイトの「WHOIS情報公開代行」（自分の名前や住所の代わりに、登録サイトの情報を出すサービス）が .jp にも使えるかを、申し込む前に確かめる。
・おすすめ：公開代行が使えるなら .jp をメインにする。予算が許せば同じ綴りの .com も取り、.jp に転送する。公開代行が使えないときや費用を抑えたいときは、.com 1つでもよい。

【費用の目安（推定）】
・お名前.com の2022年6月の価格一覧では、更新料金が .com 年1,287円〜、.jp 年3,091円〜（税込）だった（https://www.onamae.com/news/domain/20220606_1/ ）。その後の円安や値上げで、今はこれより高いと考えられる。目安は .com 年1,500〜2,500円、.jp 年3,000〜4,500円くらい。両方取ると年5,000〜7,000円前後（どれも推定）。
・1年目だけ安いキャンペーンが多いので、2年目からの更新料金で比べる。.jp は、海外の登録サイトだと更新が年90ドル台という比較もある（DomainOffer）。日本の登録サイトで取るのが無難。
・レンタルサーバーの「ドメイン無料」特典には、サーバーを解約すると有料になるなどの条件がつくことが多い（推定）。条件を読んでから使う。

【ハイフン】
・入れないのが基本。口で伝えるとき「ハイフン」「マイナス」「ダッシュ」と言い方が割れ、打ち忘れも多い。ハイフンなしの綴りを他人が持っていると、打ち忘れた人がそちらに行ってしまう。検索順位で得になることも、ほぼない（推定）。
・ハイフンなしが取れないときは、ハイフンを足して逃げない。まず .jp と .com のもう片方を見て、両方だめなら次の順位の名前に移る。

【長さと綴り】
・今は URL を打つより、SNS のリンクや名前の検索から来る人が多い（推定）。ドメインは「口で1回言えば伝わる」短さを優先し、名前と一字一句同じでなくてよい。machi/mati、tsu/tu、kapu/capu のように綴りがゆれる音は、少ないほうがよい。

- 受け止められ方: ・一番の気がかりは町田市との混同。読みの頭が「まちだ」で、3回の検索はどれも町田市の情報ばかりだった。町田市は自分の事業に「まちだ〇〇」という名前をよく付け（『まちだ未来づくりビジョン2040』『まちだイチオシ！』など）、ハッシュタグ「#まちだゴト」も使っていた。全国の自治体の制度を比べるサイトなのに、名前が「町田市の公式の取り組み」や「町田の地域情報」に見えるおそれがある。ハッシュタグの #まちだま も、町田の話題と混ざりやすい（推定）。
・「お年玉」は「もらえるお金」を表す言葉なので、損になる街（マイナスの結果）と合わない。また「玉」に3つの意味（カプセル・100円玉・お年玉）を重ねた工夫は、説明を読まないと伝わりにくい。名前だけでは「引っ越しと子育てのお金のサイト」だと分かりにくく、キャッチコピーに頼ることになる。
・「だま」は「だます（騙す）」と同じ音。住宅の資料請求などのアフィリエイトで収益を得るサイトなので、批判したい人に「まちだまし」ともじられる余地がある（推測）。
・よい点：「自治体ガチャ」のような格差を批判する言葉とは結びつかない。子育て中の家族が見て嫌な気持ちになる言葉でもない。短くて言いやすく、「AIが作った量産サイト」らしさも薄い。
・それでも使う場合は、ロゴを「まち玉」「街だま」のように書けば、見た目では「町田」と区別しやすくなる。ただし、音・ドメイン・ハッシュタグでの混同は残る。
