# 候補ジャンルと採点

**結論：第1候補は「市区町村×空き家（維持費・解体・売却の比較）」。** ただし「条件付き」です。立ち上げ前に、起きてから確認してほしいことが3つあります（最後の節）。

検証した6候補のうち、足切り条件に当たらなかったのは空き家だけでした。残る5つは、需要不足、競合の独占、制度変更のどれかで外れました。

## 第1候補「空き家」の中身

### なぜ勝てる見込みがあるか

1. **空いている場所が観察できた。** 「空き家 維持費 計算 シミュレーション」「空き家 持ち続ける 売却 解体 比較 10年 総額」で検索しても、入力して総額を出すツールは1件も出なかった。上位はファイナンシャルフィールド、マネーポスト、ALSOKなどの一般記事。
2. **市区町村ごとに答えが変わる。** 都市計画税率（0〜0.3%、例：浜松市0.3%・徳島市0.275%・北島町0.05%）、解体補助金の上限と要件（白河市50万円、北本市30万円、館林市1/2・上限60万円…）、解体後の固定資産税の減免（総社市・加賀市・深谷市にあり、千曲市は「適切でない」と回答）、空き家率。量産ページが「名前の差し替え」にならない。
3. **収益源が強く、分散できる。** 不動産一括査定はイエウール9,428円、リビンマッチ10,000円、おうちクラベル14,400円、イエカカク11,000円、タウンライフ不動産9,260円、RE-Guide 8,960円（空き家の処分を考える40〜60代向けとうたう案件）。ほかに訳あり物件買取プロ11,000円、みんなの0円物件7,700円、HOME4U土地活用22,000円、遺品整理（ライフリセット7,300円）。成果地点は「査定申込」と浅い。単価はAffisearch掲載値で、ASP管理画面では未確認。
4. **ノリマネーの型がそのまま使える。** 「車の維持費」→「家の維持費」。計算の前提（税・保険・管理費）を自分で説明できる。広告主もユーザーの場面も重ならない。

### どこで負けるか（反証役2人の指摘）

- **補助金の一覧を主役にすると負ける。** 「◯◯市 空き家 解体 補助金」は、船橋・北九州・函館・宇都宮・さいたまの全部で、公式PDFと補助金ポータル・生活ガイド.com・ミツモアが上位を占めていた。山梨県・岐阜県・大分県は市町村の補助制度の一覧を公式に出している。→ 補助金は「あり/なし・上限・受付期間・公式URL・確認日」だけにとどめる。
- **解体費の計算だけでは負ける。** クラッソーネが約110自治体と連携し、神戸市・茅ヶ崎市・館林市・滋賀県が公式サイトでクラッソーネの解体費用シミュレーターを案内している。→ 解体費は入力欄の1つにとどめ、「10年総額の比較」を主役にする。
- **売却相場の検索は大手に押さえられている。** 「宇都宮市 空き家 売却 相場」は上位9件中6件がダイヤモンド不動産研究所の町丁目別ページ。→ 相場ページでは正面から争わず、「空き家・相続・築古」の判断材料で差をつける。
- **需要が足りない可能性（足切りK3の境界）。** 推定ではジャンル全体で月30万〜80万検索。AI要約による目減りを引くと、確定EPC40円の前提では足りない。ただし主力の一括査定は単価約1万円なので、確定EPCが200円あれば必要セッションは月約1.7万まで下がる。**キーワードプランナーとASPのEPCで判断が逆転しうる。**
- **高単価の不動産案件はクローズドASPに偏っている。** Affisearchの集計で不動産81件のうちレントラックス30件、タウンライフ11件、アクセストレード8件。新規サイトでオープンASPから3社以上と提携できるかが未確認（足切りK4）。

### 採用する形（反証を踏まえた修正）

| 元の案 | 修正後 |
|---|---|
| 全国1,741市区町村の補助金一覧 | **政令市・中核市・空き家率上位の約300市**に絞る |
| 補助金・相場を主役に | **「持ち続ける・解体して更地・売る」10年総額の比較ツール**を主役に |
| 一般的な情報記事を入口に | 入口は個別計算・判断の検索に寄せる（「空き家 解体 固定資産税 いくら上がる」「実家 売るか 持つか」「◯◯市 空き家 解体後 減免」） |
| 「固定資産税が6倍」 | 「住宅用地特例が外れると土地の税は最大6倍、実際は約3〜4倍（神戸市は約3.5倍と説明）」と前提を書く |
| 毎年すべてを更新 | 毎年3〜5月に一括で見直す。各市のページに「確認日」と「出典PDF」を表示 |

### 1回目から分かった、ジャンル以外の発見

- **バイク・自転車はノリマネーに入れるのが合理的。** 審査役3人とも一致。車種ごとの差が薄く、主力案件がバイク王にほぼ集中（約2,858〜3,300円）。ノリマネーの二輪カテゴリとして作れば、テンプレートと計算機をそのまま流用できる。
- **計算機1本で済むテーマ（失業保険・年収の手取り・遺族年金・高額療養費）は量産に向かない。** パラメータを変えただけのページはスパムポリシーに触れやすい。どこかのサイトの「補助ツール」として持つのがよい。
- **腕時計・楽器・結婚式場は、データの出どころがない（坪単価と同じ理由）。** 腕時計買取は単価が高い（時計買取.biz 10,000円）が、成果条件が「着荷」と重い。

## 起きてから最初に確認してほしいこと（ここで足切りが決まる）

1. **ASPの管理画面で、不動産一括査定・訳あり/空き家買取の提携先を数える（K4）。**
   A8.net・もしも・バリューコマース・アクセストレード・afbで、イエウール／リビンマッチ／おうちクラベル／イエカカク／HOME4U／すまいステップ／RE-Guide／ワケガイ／訳あり物件買取プロなどを検索。**同じ成果地点（査定申込）の広告主が3社以上・2ASP以上** あれば合格。あわせて表示EPCと確定率をメモする。
2. **キーワードプランナー（またはラッコキーワード）で需要を測る（K3）。**
   測る語の例：空き家 売却／実家 売却／空き家 買取／空き家 固定資産税／空き家 維持費／空き家 解体 費用／相続 空き家 3000万円控除／実家 売るか 持つか／（政令市・中核市名）空き家 売却。
   判定：必要セッション＝10万円÷（CTR×確定EPC）。その10倍以上の合計があれば合格。ノリマネーのデータページの実測CTRを使う。
3. **Google日本をシークレットウィンドウで開き、代表語を10個見る（C3）。**
   「空き家 維持費 計算」「実家 空き家 売るか 持つか」「空き家 解体 固定資産税 いくら上がる」などで、上位5位を公式・大手・比較サイトが独占していないか。AI Overviewが出るかも数える。

**どれかが不合格なら、無理に2つ目のサイトを作らず、ノリマネーの拡張（バイク・通勤コスト比較）に時間を回す方が、1人運営での損失は小さい**、というのが最終チェック役の意見です。
