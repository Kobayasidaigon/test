# サイト設計書：アキヤマネー（仮称）

**一言で：** 実家の空き家を「持ち続ける・解体して更地で持つ・売る」の3つで、市の税率と補助金を入れて10年分計算するサイト。

- 名前はノリマネー（乗り物×お金）にそろえた仮の名前です。別案：「実家の明細」。
- 試作は `site/public/` にあります（`node site/src/build.mjs` で作り直せます）。

---

## 1. 誰の、どの場面のためのサイトか

| | |
|---|---|
| 読む人 | 親の家を相続した、またはこれから相続する40〜60代。実家から離れて住んでいることが多い |
| 場面 | 春に固定資産税の納税通知書が届いたとき／相続の手続きのあと／親が施設に入ったとき／「管理不全空家」の通知が来たとき |
| 知りたいこと | 持ち続けると毎年いくらかかるか。壊すと税金が上がるのは本当か。売ったらいくら残るか。いつまでに決めればいいか |
| このサイトでしてほしいこと | 自分の家の条件を入れて10年明細を見る → 売る場合の値段を一括査定で確かめる |

ノリマネーの「車の維持費」を「家の維持費」に置き換えた形です。計算の前提（税・保険・管理費）を運営者が自分の言葉で説明でき、広告主もノリマネー（車買取・自動車保険）と重なりません。

### 市区町村ページを公開する条件（スパムポリシー対策）

テンプレートの名前を差し替えただけのページにしないため、**次の3つが公式資料で確認できた市だけ公開**します。

1. 都市計画税の税率（課税していない場合はその事実）
2. 住宅地の地価公示の平均（国交省・県・市の資料）
3. 解体の補助金の有無と、あれば補助率・上限・要件・受付期間

この3つで計算結果が市ごとに変わります。加えて、空き家率、解体後の減免、空き家バンク、相談窓口、その市の空き家計画の事実を載せます。1ページに「行ごとに違う値」が5項目以上ある状態を保ちます。

**試作ではビルドで自動判定しています。** 3項目のどれかが「未確認」か、出典つきの事実が5件未満の市は `noindex` になり、sitemap にも入りません（いまは北九州市だけが公開、宇都宮市と加賀市は noindex）。市ごとの手書きの解説（`site/src/data/commentary.json`）も、量産ページにしないための必須項目です。

## 5. 収益の導線と、月10万円までの計算

### 主力の広告（Affisearch掲載値。ASP管理画面では未確認）

| 種類 | 案件の例 | 単価 | 成果地点 |
|---|---|---|---|
| 不動産一括査定 | イエウール 9,428円／リビンマッチ 10,000円（税抜）／おうちクラベル 14,400円（税抜）／イエカカク 11,000円／タウンライフ不動産 9,260円（税抜）／RE-Guide 8,960円（税抜。空き家の処分を考える40〜60代向けとうたう） | 約9,000〜14,400円 | 査定申込 |
| 空き家・訳あり買取 | 訳あり物件買取プロ 11,000円／みんなの0円物件 7,700円 | 7,700〜11,000円 | 査定申込・問い合わせ |
| 土地活用（解体後の人向け） | HOME4U土地活用 22,000円（レントラックス） | 22,000円 | 問い合わせ |
| 遺品整理 | ライフリセット 7,300円（税抜） | 2,000〜7,300円 | 見積依頼 |

**注意：** 不動産の高単価案件はレントラックスなどのクローズドASPに偏っています（Affisearchの集計で不動産81件中30件）。立ち上げ時に **A8・もしも・バリューコマース・アクセストレード・afb で、査定申込の広告主が3社以上・2ASP以上** 提携できるかを最初に確かめてください（足切り条件K4）。

### 導線の置き方（試作で実装済み）

1. 計算ツールの「1年目に売る」の列は、地価の平均から出した仮の数字にしてある → 「自分の家の本当の値段を知りたい」という次の行動が自然に出る
2. その直後の節で、一括査定（売る義務はない・複数社から連絡が来る、を正直に書く）と買取（仲介より安くなるのが一般的、と書く）を並べる
3. 全ページの最上部と広告枠に「PR」表記。広告の有無で計算結果を変えないと明記

### 月10万円の計算（推定。ASPの実績値で置き換える）

```
確定EPC ＝ 単価10,000円 × 成約率2% × 承認率60% ＝ 120円/クリック（推定）
必要クリック ＝ 100,000円 ÷ 120円 ≒ 830クリック/月
必要セッション ＝ 830 ÷ 広告へのクリック率3% ≒ 28,000セッション/月
```

ツールの結果を見た人が査定ボタンを押す率は、一般記事より高いと見込みます（推定）。ノリマネーの計算ツールページの実測クリック率があれば、それで置き換えてください。成約率・承認率は、ASPの管理画面の表示値（A8なら確定率）を使います。

## 6. データの集め方と更新

| 項目 | 一次資料 | 更新 |
|---|---|---|
| 都市計画税の税率 | 市の税のページ、都道府県の「市町村税務概要」 | 年1回（4月） |
| 住宅地の地価公示の平均 | 国交省 不動産情報ライブラリ、県・市の地価公示の抜粋 | 年1回（3月下旬公表） |
| 解体の補助金 | 市の空き家対策のページ、県の市町村補助制度一覧（山梨・岐阜・大分などは公式に一覧がある） | 年1回（3〜5月）＋受付終了の告知 |
| 解体後の減免 | 市の税のページ（総社市・加賀市・深谷市などに例） | 年1回 |
| 空き家率・空き家数 | 総務省 住宅・土地統計調査（5年ごと。次は2028年調査） | 5年に1回 |
| 水道の基本料金 | 市の上下水道局 | 改定の告知時 |
| 全国共通の税制 | 国税庁、総務省、法務省 | 毎年12月の税制改正大綱のあと |

**運用ルール：** 毎年3〜5月に全市を見直す。各市のページに「確認日」と出典URLを出す。公式で確かめきれない値は「要確認」と表示し、補助金は確認できるまで計算に入れない（試作でそうしている）。

**作業量の目安（推定）：** 1市あたり新規30〜45分、更新15分。300市なら年次更新は約75時間（月にならすと約6時間）。

## 8. デザインの考え方

運営者に渡されたスキル（taste-skill、impeccable）に従いました。

- **題材から取った着想：** 空き家の持ち主に毎年春に届く「固定資産税の課税明細書」。ヒーローの左に、入力に連動する「課税明細書（見本）」を置いた。計算結果も、費目・金額・合計を二重線で締める「10年明細」の表にした。入力欄にも「課税明細書の地積」「課税明細書の価格」と、手元の書類のどこを見ればいいかを書いた。
- **フォント：** BIZ UDPゴシック1種類。公的な書類にも使われるUD（ユニバーサルデザイン）書体で、40〜70代の読者が読みやすい。
- **色：** 漆喰の白の地・墨・納付書の緑。「売る・手放す」の節だけ、いぶし瓦の色の地にした。税が上がる箇所だけ赤茶。
- **避けたもの：** 中央寄せの見出し、見出しの上の小さなラベル、01/02/03の番号、アイコン付きのカードの並び、グラデーション、影、紫、絵文字、架空の口コミや利用者数。
- **絵：** 写真がないので、「家を壊すと税が上がる」の節にだけ、雨戸を閉めた家と更地の絵をコードで描いた。**公開前に、運営者が撮った本物の空き家の写真（実家・近所。人物や表札が写らないもの）に差し替える**と、サイトでいちばん代わりのきかない一次情報になる。

## 9. 技術

- 静的サイト。`node site/src/build.mjs` で `site/public/` に全ページを書き出す。外部ライブラリは使っていない。
- 計算は `site/src/calc.js` に1つだけ。ビルド時に各市のモデルケースを計算して静的な表に書き出し（JavaScriptを実行しないAIのクローラーにも読める）、ブラウザでは同じ関数で入力から計算し直す。
- 市を足す：`site/src/data/cities.json` に1件足してビルド。
- 公開先の候補：Cloudflare Pages／Netlify／GitHub Pages（どれも無料枠で足りる）。`site/public` をそのまま置く。
- 入力した数字はブラウザの中だけで計算し、送信も保存もしない。

## 10. リスクと対策

| リスク | 対策 |
|---|---|
| 需要が足りない（K3が境界） | 起きてから計測。足りなければ中止して、ノリマネーの拡張へ |
| オープンASPで提携できる査定案件が少ない（K4） | 起きてから確認。実績が出たらレントラックスなどに申請 |
| 量産ページがスパムと見なされる | 公開条件の3項目、出典・確認日、最初は50ページで評価を見る |
| 補助金・税率の誤り（YMYL） | 公式資料だけを出典にする、要確認の表示、補助金は確認できるまで計算に入れない、毎年3〜5月に見直す |
| 3,000万円控除が2027年末で終わる | 計算の変数1つで切り替えられる。終わる前後は「期限」の検索が増える見込み |
| 一括査定の連絡が多いという不満 | 「複数社から連絡が来る」と事前に書く。買取の選択肢も並べる |
