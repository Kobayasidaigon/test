# 住む街ガチャ 第2ラウンドの検証結果

第1ラウンドのレポートの土台になっていた「推定」「未確認」の主張を、10人の担当が検索で確かめた結果です（検索は合計108回）。レポート本体（05_sumumachi_report.md）は、この結果を反映して更新済みです。

## 結論

やる価値はあるという結論は変わらない。看板の「隣の市で年に数十万円」は、0〜2歳の子がいる共働き家族が、東京都と第1子の保育料が有料の隣の市を比べる場合に成り立つ。確かめられたのは足立区・北区と草加市（令和8年度の公式表）で、1歳の第1子なら年約39万〜65万円（所得割は推計なので推定）。一方、市川市と大阪市が2026年9月に第1子の保育料を無償にし、差が消えたり向きが変わったりしているので、差には寿命があると考え、確認日つきで出して年2回見直す必要がある。向かい風も4つ見つかり、どれも公開前に手当てが要る。名前の問題（「ガチャ」は登録商標で、「自治体ガチャ」は格差を批判する言葉）、直接の競合「まちくらべ」、FP相談・賃貸の単価の下方修正、レジストリが申請制であること。
