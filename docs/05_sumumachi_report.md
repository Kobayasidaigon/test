# 住む街ガチャ 事前調査レポート（2026年11月1日時点）

このレポートの材料は、分野ごとの調査をまとめた3つの章（データと計算モデル／集客と収益／体験とデザイン）と、推進役・慎重役の意見だけです。新しい検索はしていません。

数字には次の印を付けています。
- 推定: 根拠はあるが、確定していない見込み
- 未確認: まだ確かめられていないこと
- 仮置き: 根拠が見つからず、仮に置いた値（公開後に実際の数字で置き換える）

年度は、令和8年度（2026年4月〜2027年3月）を基本にしています。

---

## 1. 結論

**やる価値はあります（条件つき）。**

- 家族の条件を入れて「隣の市と年にいくら違うか」を円で出す専用ツールは、今回の検索では見つかりませんでした（未確認）。
- 差の大きい制度は実際にあります。0〜2歳の保育料、東京都の018サポート（子1人年6万円）、中学校の給食費、移住支援金の自治体差などです。
- 全国の土台になる国のデータ（医療費助成・家賃・下水道など）は一括で取れます。
- 動き・感情・名産で結果を見せる既存サイトは見当たりません。

**条件**
1. **看板の数字を正直に作る。** 国の制度が手厚くなり、自治体ごとの支援の差だけで「年に数十万円」になる家族は限られます。年額で数十万円になりうるのは、0〜2歳の保育料（都県境。未検証）と家賃（推計）くらいです。それ以外の差は「5年で◯万円」「下の子が18歳になるまでで◯万円」と、前提をつけて見せます。
2. **地域を絞って始める。** 首都圏の都県境と大阪市周辺の約40〜60市区から始めます。全国分は「目安版」として下地に置きます。
3. **収益の柱を、単価の高い案件に置く。** 引越し見積もりは1件381〜1,600円と安いので、柱は注文住宅の資料請求・FP相談・売却査定にします。移住先での転職は、移住支援金を受けるルートでは収益になりにくい点にも注意します。
4. **期限の余裕は小さいと認める。** 「18ヶ月で月10万円」はぎりぎりの計画です。初到達は2028年1〜3月（14〜17ヶ月目）を狙い、手前の目標を月3万円とします。途中で判断する時期も先に決めておきます。

**最初の一歩（2026年11〜12月）**
1. 東京都と隣接市の令和8年度の保育料表で、モデル家族の年額を手で計算する。
2. ASPに登録し、単価・承認率・対応エリアを管理画面で確かめる。
3. 週に使える作業時間を見積もり、春に公開する最小限の範囲を決める。
4. 「ガチャ」という名前が商標登録されていないか、どう受け止められるかを確かめる。

## 2. サイトの形

### 入力
- **必須**: 今住んでいる市区町村、子どもの人数と年齢（生まれる予定の子も含む）、働き方、希望家賃
  - 働き方の選択肢: 通勤する会社員／今の仕事をリモートで続ける／移住先で転職／自営業・フリーランス／パート・時短
- **任意**: 世帯年収の帯、0〜2歳の子の保育園利用、妊娠中かどうか、22歳の年度末までの上の子、23区に住んでいた・通っていた年数、持ち家かどうか、都市ガスかプロパンか、引越し費用
- 計算は利用者の端末の中だけで行い、入力内容は送信しません。

### 何が出るか（物差しは「今の街との差」）
- **毎年の差**: 2本の棒で見せます。
  - 支援の差: 医療費・保育料・給食費・独自の給付など
  - 暮らしのお金の差: 家賃・上下水道・国民健康保険（国保）など
- **一度きりのお金**: 移住支援金・出産祝い金は、別の「もらえるかもメーター」で見せます。返還条件・受付状況・税金の注意を必ず添えます。
- **合計に入れないもの**: 住宅補助（抽選や予算枠があるため）と臨時の給付は、合計の外に「ボーナス候補」として並べます。
- **国の土台**: 児童手当など全国一律の制度は差に入れず、「どこに住んでももらえるお金」として明るく見せます。
- **仕事カード**: 年収・求人倍率・最低賃金は合計に入れず、横に並べます。
- **期間の切り替え**: 1年目／5年合計／下の子が18歳になるまで／1年あたり。
  - 最初にどの期間を見せるかは、章によって案が分かれています。計算モデルの章は5年合計（移住支援金の返還期間に合わせる）、体験の章は年額を推しています。試作を人に使ってもらって決めます。
  - シェア画像の大きな数字は「毎年の差」に固定します。

### ランキングの決め方
- **働き方で候補を絞る。**
  - 通勤する人: 今の街と勤務地の周りから選び、支援の差と暮らしのお金の差を合計して出します。
  - リモート・移住先で転職・自営の人: 全国か選んだ県から選び、支援の差と暮らしのお金の差を別々のランキングにします。
- 推計の項目は幅で示し、順位は幅の下限（控えめな値）で付けます。
- その家族にとって大きい項目（例: 0〜2歳の子がいる家族の保育料）が未確認の街には、順位を付けず「確認中」と出します。
- 両方の街が同じ平均値で代用されている項目は、差を0円にせず「不明」と出します。
- 順位は帯（グループ）で見せ、全国のワースト一覧は作りません。「全国◯位（掲載◯市町村中）」は上位の帯に入ったときだけ出します。

### 手作業で集めるもの
- **0〜2歳の保育料**: 市ごとの基準額表で、形式がばらばら。毎年4月に改定され、所得の基準は9月に切り替わる（推定）。

## 4. 計算モデルと、最初に作る範囲（MVP）

### 計算式
```
年間の得 ＝ 支援の差（候補の街でもらえる・浮くお金 − 今の街の分）
          ＋ 暮らしのお金の差（今の街で払うお金 − 候補の街で払うお金）
N年合計 ＝ 各年の「年間の得」の合計 ＋ N年以内に確定する一度きりのお金 − 引越し費用
```
- **子どもの年齢を1年ずつ進めて計算する。** 例えば、保育料は3歳で止まります。中学校の給食費は中1〜中3の年だけ、高校生の医療費は高1〜高3の年だけ入ります。
- **二重に数えない。** 国の土台（児童手当、小学校給食への国の支援 年57,200円など）は差に入れません。移住支援金は、自治体ごとの実際の額を1つだけ使います。
- **項目ごとの計算**
  - 医療費助成: 年齢別の医療費×負担割合−自治体の一部負担。「平均の目安」と「控えめな値」の2本で幅を出す。
  - 中学校給食: 月額×11か月。
  - 保育料: 年収帯から市の階層表を引く。
  - 家賃: 希望家賃×(1−候補の街の1畳当たり家賃÷今の街の1畳当たり家賃)×12。「同じ家賃なら何畳借りられるか」も出す。
  - 上下水道: 料金表×世帯人数別の平均使用量。
  - 国保: 自営業・フリーランスのときだけ計算に入れる。

### 計算の見本（調査で集めた数字で試算）
- **見本1: 子ども2人（1年目は中1と小6）**
  - 前提: 候補の街だけが、中学校給食を無償にし、高校生まで通院費を助成している（仮の組み合わせ）。
  - 結果: 年額は最大でも約12万円。5年合計で約46万円、下の子が18歳年度末になるまでで約57万円（推定）。
  - わかること: 「隣の市で数十万円」は、何年分かの合計で見せるのが正直なやり方です。
- **見本2: 23区から地方へ移住する、子ども2人の家族**
  - 国の上限どおりに出す自治体なら300万円、札幌市（令和8年度）なら80万円で、220万円違います（試算。[札幌市](https://www.city.sapporo.jp/keizai/koyo/ijyu_shienkin/iju_shienkin0804.html)）。
  - わかること: 毎年の差とは桁が違うので、同じ棒に積まず別のメーターで見せます。
- **見本3: 都内に住む共働きの家族（1歳の第1子）が、隣の県の市を候補にした場合**
  - 支援の差: 018サポートの分で年−6万円（[東京都](https://www.fukushi.metro.tokyo.lg.jp/kodomo/kosodate/018/index.html)）。保育料は都内なら無償ですが、候補の市の額は確認中です。
  - 暮らしのお金の差: 家賃が安ければプラスになりえます（推計）。
  - 見せ方: 2本の棒で正直に見せ、保育料が確認できるまでは順位を付けません。

### 家賃が他の項目を飲み込む問題
希望家賃8万円の家族の場合、街の家賃水準が1割違うだけで年9.6万円、5年で48万円の差になります（仮の計算）。これは見本1の5年合計とほぼ同じです。そのため、次の手を打ちます。
- 働き方で候補を絞る。
- 支援の差と暮らしのお金の差を、2本の棒に分けて見せる。
- 家賃は比で推計し、広さ（畳数）でも見せる。
- 候補の街の家賃を、利用者が自分で入れ直せる欄を置く。
- SNSで見せる主役は、全国ランキングではなく「隣の市」カードにする。

### MVP（2027年2〜3月に公開）
- **下地（案A）**: 全国一括で取れる医療費助成・家賃・下水道・最低賃金など。「目安版」と明記します。
- **主役（案B1）**: 首都圏の都県境と大阪市周辺の約40〜60市区。保育料・独自の給付・中学校給食などの手作業の項目まで入れます。約50市区×約10項目で、約500項目になります（試算）。
- **春の公開に入れるもの**（慎重役の案を採用）: 計算ツール1本、差を確かめた隣接ペアの比較ページ、5段階の表情の静止画とCSSの動き、縦長のシェア画像1種類。
- **第2段階に回すもの**: 移住支援金の特集（案B2。群馬・栃木・長野など数県）、Rive・Lottieを使ったアニメーション、横長のリンクカード画像の自動生成、全国の名産バッジ。計算モデルの章はB2を並行して始める案でしたが、ここでは折り合いとして、データ集めだけを並行し、公開は作業時間に余裕があれば、とします。
- **データ台帳**: 1行を「自治体×項目×年度」にし、各行に出典URL・確認日・確からしさ・受付状況・適用期間を持たせます。確認日が古くなった値は、自動で「前年度」「確認中」の表示に切り替えます。

## 5. 動き・感情・「有名なもの」の表現

### 感情の見せ方
- **家族の表情は「毎年の差」だけで決め、5段階で切り替える。**
  - 段階: ◎大きく増える／○増える／＝ほぼ同じ／△減る／▽大きく減る
  - 段階の境目の金額は、試作を人に使ってもらって決めます。
  - 一度きりのお金は表情に入れません。大喜びさせると、利用者が支援金の条件を見落とすおそれがあるためです。
- **結果は三幕で見せ、最後は必ず前向きに終える。**
  - 流れ: いまの街 → この街なら → 次の一歩
  - 今の街が上位なら、「今の街、実はかなり手厚い!」と祝います。
- **悲しむのは貯金箱（家族の財布）だけにする。**
  - 町・名産・住民は悲しませず、子どもは泣かせません。
  - 「ハズレ」「負け」「損な町」「ワースト」という言葉は使いません。
  - 自虐の一言は家族に向けます（例:「うちの家計、年◯万円ぶん見逃してた」）。
  - 根拠（追い風）: 褒め言葉だけの結果より、ネガティブな要素を笑いに変えた結果のほうがSNSで広がる、という分析があります（[Makko診断ポータル運営会社の自社分析。第三者の検証はなし](https://prtimes.jp/main/html/rd/p/000000016.000143217.html)）。
  - 根拠（向かい風）: 下位扱いされた自治体の首長が反発した前例があります（[2021年 群馬県知事](https://www.bengo4.com/c_23/n_13673/)、[2024年 島根県知事](https://gendai.media/articles/-/130780)）。
- **細かい演出**
  - 家族一人ひとりが、自分に関係する制度に反応します（赤ちゃん＝保育料、高校生＝医療費、親＝家賃・支援金・仕事）。
  - まだ確かめていない制度がある街では、キャラが虫めがねを持って控えめな表情にします。
  - 差額を「習い事◯か月分」のように言い換えるときは、商品名ではなく一般名を使います。

### ガチャの演出
- 結果は計算で決まります。ランダムではなく、課金もありません。
- 流れ:
  1. 入力に答えるたびに、家族がそろっていく。
  2. レバーを回す（計算中の演出）。
  3. カプセルが開いて、ご当地はんこがポンと押される。
  4. 上位の街のカプセルを3つほど開ける。
  5. はんこがスタンプ帳にたまる。
- 「もう1回」は、条件を変えて回します（例: 子どもが中学生になったら）。
- レア度・当たり・ハズレの表現は使いません。

### 県や仕事の「有名なもの」
- **世界観**: 家族キャラ・名産の食卓・ご当地はんこ・天秤・貯金箱の5つでそろえます。
  - 名産の食卓は、得が大きいほど料理が増えます。減らす方向には使いません（名産を悲しませないため）。
- **県バッジ**: 全国一律の統計から、全県同じルールで最大3つ選びます。
  - 選ぶ順の例: 農業産出額で上位の品目 → 県内トップの製造業 → 伝統的工芸品（[244品目](https://www.meti.go.jp/press/2025/10/20251027001/20251027001-a.pdf)）→ 県の花・木・鳥
  - 「りんご 全国1位（令和6年・東北農政局資料）」のように、出典と年度を一行添えます。
- **街バッジ**: 産地だと確かめられたものだけを、人口の多い地域から人の手で整えます。
- **仕事の見せ方**
  - 親キャラの服装を、入力した働き方に合わせて着せ替えます。
  - 「この街に多い仕事」バッジを出します。国勢調査の職業大分類から、全国平均の何倍かを自分で計算します。
  - 年収・求人倍率・最低賃金の仕事メーターを、年度つきで出します。
  - ネタの例: 「仕事の見つけやすさ日本一は東京じゃない」。令和7年平均の有効求人倍率は、実際に働く場所で数えると福井（1.84倍）が1位、求人を受け付けた場所で数えると東京（1.73倍）が1位です（[JIL](https://www.jil.go.jp/kokunai/blt/backnumber/2026/04/c_01.html)）。
- **注意**: 同じ県の隣どうしの市では、県バッジが同じになります。隣の市との差は支援と家賃で作り、名産と仕事は背景や喜びの演出に使います。
- **収益へのつなぎ方**: 名産はふるさと納税に「住む前に味見」としてつなぎます（ポイント還元はうたいません）。産業は転職の2つのルート（支援金ルート／年収ルート）につなぎます。
- **先行例**: 名産で町を見せる手法は、桃太郎電鉄で広く受け入れられています（[gamebiz](https://gamebiz.jp/news/280659)）。ただし強い先行者なので、物件カード風の画面や桃鉄の用語は避け、はんこと食卓という別の仕組みで見せます。

### 技術
- **全体の形**: 静的サイトにし、計算は利用者の端末の中で行います。
- **動きの土台**: SVGのパーツとCSS・GSAPで作ります。
  - GSAPは、2024年秋にWebflowに買収された後、全機能が無料・商用利用可になりました。残っている禁止事項は未確認です（[Webflow](https://webflow.com/blog/gsap-becomes-free)）。
  - Riveは任意です。ファイルの書き出しには有料プランが必要で、再生用のプログラムはMITライセンスです（[Rive](https://rive.app/blog/new-pricing)）。
  - Lottieも任意です。無料素材は商用利用可ですが、作者ごとに条件を確かめます（[LottieFiles](https://help.lottiefiles.com/hc/en-us/articles/900002438343-Can-I-use-a-free-animation-on-Lottiefiles-for-commercial-business-use)）。
  - RiveとLottieは、結果を出すときにだけ読み込みます。
- **画面の切り替え**: 1ページの中でView Transitionsを使います。2025年10月のFirefox 144で、主要ブラウザすべてが対応しました（[web-features](https://web-platform-dx.github.io/web-features-explorer/features/view-transitions)）。
- **表示速度**: 動かすのは位置・大きさ（transform）と透明度（opacity）だけにします。web.devの比較例では、top/leftを動かすとフレームの50%が落ち、transformでは約1%でした（[web.dev](https://web.dev/articles/animations-guide)）。最初の画面はCSSだけで作ります。
- **体にやさしい作り**
  - 端末の「動きを減らす」設定の人には、演出を出さずに静止画で結果を見せます。
  - 1秒に3回を超える点滅はしません（[WCAG](https://w3c.github.io/wcag/understanding/animation-from-interactions.html)）。
  - 全員に演出スキップのボタンを用意し、効果音は最初はオフにします。
- **シェア画像**
  - 縦長（ストーリーズ・LINE向け）: 端末の中で画像を作り、スマホの共有機能（Web Share API）で渡します。使えない端末では「画像を保存」に切り替えます。Instagramのストーリーズへ直接渡せるかは未確認です（[web-features](https://web-platform-dx.github.io/web-features-explorer/features/share)）。
  - 横長（X・LINEのリンクカード）: Cloudflare WorkersとSatoriで作り、R2に保存して使い回します（[Zenn](https://zenn.dev/uzimaru0000/articles/satori-workers)）。悪用を防ぐため、受け付ける値は市町村コード・1万円単位に丸めた金額・決まったコピーの番号だけにします。
  - 必ず「試算」「年度」「計算日」「前提」を入れます。子どもの年齢・家賃・住所は、本人が選んだときだけ載せます。

### 権利と「AIで作った感」の回避
- **使わないもの**
  - ご当地キャラ（くまモンは熊本県の許諾制で、特定の商品を勧める使い方は禁止。[熊本県](https://www.pref.kumamoto.jp/uploaded/attachment/114769.pdf)）
  - 県章・市章、観光協会の写真、ロゴ
  - 名産に顔を付けた擬人化、写真のトレース
- **地域団体商標の名前**（夕張メロンなど）: 説明文の中だけで使い、見出しや画像の大見出しには使いません。商標法26条の一般的な考え方にもとづく推定なので、迷う表現は弁理士かINPITに相談します（[特許庁FAQ](https://www.jpo.go.jp/system/trademark/gaiyo/chidan/faq.html)）。
- **絵**: 家族キャラは、一人のイラストレーターにオリジナルで発注します。費用は、バストアップ5体で数万〜十数万円に収まる可能性があります（推定。[ココナラの相場](https://coconala.com/magazine/15477)）。商用利用・改変・アニメーション化・広告での利用・著作権の扱いは、書面で決めます。
- **言葉と運営**: 出典つきの具体的な一文を書き、計算式・編集方針・更新履歴を公開します。AIで大量に作った診断サイトについて、開発者自身が「アドセンスの審査に通るわけがない」と書いた例があります（[Qiita](https://qiita.com/fuga-if/items/9fed3e53191b2b2604a5)）。

### 結果の型ごとに出す案件
結果画面には「シェア」「計算の根拠」と並べて、「住めるか確かめる（家賃・家・仕事・引越し代・家計）」ボタンを置きます。案件は、確かめる作業の続きとして見せます。結果画面にはディスプレイ広告を置きません。

- **近くに引っ越すと得**: 引越し見積もり（「引越し代を引いた実質の得額」を出す計算の一段階として）、賃貸、光回線。家を建てる人には注文住宅の資料請求、持ち家の人には売却査定。

- **今の街が一番**: 注文住宅の資料請求、FP相談、ふるさと納税。
- **差が小さい**: FP相談。
- **家族の段階に合わせる**: 妊娠中〜未就学の子の家族にはFP相談を出します。住み替えを具体的に検討している人の割合は、妊娠中がいちばん高い20.9%です（[赤ちゃん本舗の調査](https://prtimes.jp/main/html/rd/p/000000724.000018863.html)）。子育て世代の7割が戸建て志向で、住み替えの予算は3,000万円台が最多です（[コズレ 2025年](https://resemom.jp/article/2025/08/04/82861.html)）。そこで「この街で3,000万円台の家」から資料請求へつなぎます。

## 8. 法務と正確性

- **ステマ規制**: 令和5年内閣府告示第19号（2023年10月1日施行）で、アフィリエイトも対象です（[西村あさひ](https://www.nishimura.com/sites/default/files/newsletters/file/corporate_230403_jpn.pdf)）。
  - 広告枠ごとに「PR」と表示し、ページの冒頭に「本ページはプロモーションを含みます」と書きます。
  - 結果と広告は背景色で分け、編集方針に「順位は広告の有無で変わらない」と書きます。
  - 告示の原文は、消費者庁のサイトで確認します。
- **住宅ローン**: 比較やランキングはしません。銀行法・金融商品取引法・景品表示法・貸金業法などが重なるためです（[解説](https://www.seedinc.jp/column/affiliate/housing-loan-affiliate/)）。「No.1」「審査が通りやすい」といった表現も使いません。
- **移住支援金**
  - 要件は自治体と年度で違います。令和8年度は、札幌市がテレワーク要件をなくし、[神奈川県](https://www.pref.kanagawa.jp/docs/y2w/ijushienkin.html)は残しています。
  - 国の制度の基本では、移住の直前10年間のうち通算5年以上、23区に住んでいたか23区へ通勤していたことが必要です（[補助金ポータル](https://hojyokin-portal.jp/subsidies/44208)）。
  - 返還: 3年未満で転出すると全額、5年以内なら半額を返します（[仙台市](https://www.city.sendai.jp/koyotaisaku/kurashi/machi/kezaikoyo/kyujin/ijuushien/documents/03_seiyakujikou.pdf)）。長崎市では、さらに年10.95%の加算金がかかります（[長崎市](https://www.city.nagasaki.lg.jp/site/nagasakijin/84335.html)）。
  - 税金: 一時所得として課税される可能性があります（推定）。そのため金額は税引前で表示し、注意書きを付けます。
  - 支援金が出ない転職ルートでは、支援金込みの額を見せません。
- **正確性**
  - 確かめられない項目は0円にせず、「未確認」と表示します。
  - 金額ごとに「根拠バッジ」（年度・確認日・出典）を付け、タップすると計算式と自治体の公式ページが開くようにします。
  - 結果画面に「概算です。申請の前に必ず自治体の窓口で確認してください」と書きます。
  - 修正を依頼できるフォームと「自治体確認済」のバッジを用意し、変更履歴を公開します。
- **プライバシー**
  - 入力内容は端末の中で計算し、URL・アクセス解析・広告主には送りません。
  - シェアは、結果だけが載るのを初期設定にします。
  - 2023年6月施行の外部送信規律がこのサイトに当てはまるかは未確認ですが、「外部送信について」のページは置きます（[総務省](https://www.soumu.go.jp/main_content/000832491.pdf)）。
- **表現**
  - 順位は帯で見せ、ワースト一覧は作りません。
  - 災害への配慮モードを用意し、被災した地域ではマイナスの演出とランキングを止めて、公式の支援情報へ案内します。熊本県のページに「令和8年熊本地震」という見出しが出ていましたが、内容は確認できていません（[熊本県](https://www.pref.kumamoto.jp/soshiki/3/index.html)）。
- **名前**
  - 「親ガチャ」は2021年の流行語トップ10に入り目を引く一方、賛否が割れた言葉です（[プレジデント](https://president.jp/articles/-/68421)）。
  - 候補は3つあります。キャッチコピー「親は選べない。でも街は選べる。」で意味を前向きに裏返す案、「となり町ガチャ」、「ガチャ」を外す案（「となり町くらべ」など）です。
  - 商標登録の有無を確かめたうえで、SNSで比べて決めます。

## 9. 推進役と慎重役の意見と、その扱い

| 論点 | 推進役 | 慎重役 | 扱い（リスクと対策） |
|---|---|---|---|
| 看板「隣の市で年に数十万円」 | 差の大きい制度が実在し、国のデータで裏付けられる | 支援の差だけでは、多くの家族で年額にならない。数字を盛ると信頼を落とす（対策可能） | 作る前に手計算で確かめる。年額で数十万円が確認できた家族型・ペアだけ「年◯万円」と出し、他は「5年で」「18歳までで」と前提をつける |
| 家賃 | 年9.6万円の差を、本物のお金として見せられる | いちばん弱いデータが、順位をいちばん動かす（対策可能） | 比で推計し、幅を持たせて控えめな値で順位を付ける。別の棒で見せ、利用者が家賃を入れ直せる欄を置く。不動産会社の公開相場と比を照らし合わせる |
| 収益 | 結果を見たあとの行動と、単価の高い案件が重なる。必要PVは実例の範囲 | 引越し見積もりは単価が低く、転職の支援金ルートは収益にならない。申込率は仮置き（対策可能） | 柱を住宅・FP相談・売却査定に置く。ASPで実際の値を確かめ、公開後3ヶ月の実測で計画を直す |
| 集客と期限 | 需要と拡散の実例がある。AI概要に強い型で、毎年の話題の波もある | SNSと検索に時間差がある。データサイトと大手が強く、AI概要でクリックが減る。18ヶ月の余裕は小さい（**対策しても残る**） | 月10万円の初到達は2028年1〜3月を狙う。判断点は2つ。①公開後3ヶ月で、慎重・標準・楽観のどれに近いか。②12ヶ月目（2027年11月）に月3万円が見えているか。見えていなければ、高単価の導線に集中する／比較ページを増やす／法人向けを前倒しする、のどれかを選ぶ。売却という出口を残す |
| 作業量 | 技術・データ・権利の条件がそろい、個人でも作れる | 1人で回すには多い。移住支援金の情報が古いと、利用者の返還という実害につながる（対策可能） | 春は最小限で公開し、残りは第2段階へ回す。データ台帳で確認日を管理し、古い値は自動で「確認中」にする。移住支援金は、月1回見回れる数県だけで扱う |
| 体験 | 動き・感情・名産は、既存サイトにない体験になる | 名前・悲しむ演出・順位への反発（小さめ） | 悲しむのは財布だけ、順位は帯、ワースト一覧なし。名前は公開前に決める |

## 11. 人が確かめること

1. **ASPの管理画面**（A8.net、バリューコマース、もしもアフィリエイト、afb、アクセストレード、タウンライフアフィリエイト）: 今の単価・成果になる条件・承認率・対応エリア。22,000円の表示がタウンライフ家づくりと同じ案件かは、担当者に聞く。
2. **日本のブラウザでの検索**: 日本の回線のシークレットウィンドウで、主要な言葉20個ほどを検索し、上位の顔ぶれとAI概要の出方を見る。ラッコキーワードやキーワードプランナーで検索数も調べる。
3. **保育料表のダウンロードと手計算**: 東京都と隣接市（川崎・川口・市川・相模原・草加・戸田など）の令和8年度の保育料基準額表を集める。モデル家族（0歳＋3歳、共働き、年収500万・700万・900万円）で年額を出す。大阪市と隣接市でも同じことをする。
4. **家賃データ**: e-Statで住宅・土地統計調査の原本（表121-2-2など）を取り、全国平均3,393円と照らし合わせる。
5. **医療費助成データ**: こども家庭庁の別紙3から抜き出した件数を、別紙1の集計（通院18歳年度末1,576など）と照らし合わせる。Excel版があるかを、成育局母子保健課に問い合わせる。
6. **似たツールの有無**: App Store、Google Play、X、JOIN、SMOUT、県の移住ポータルを直接見る。
7. **名前**: J-PlatPatで商標を調べ、Xで「自治体ガチャ」「住む街ガチャ」の使われ方を見る。
8. **シェアの動作**: iPhoneとAndroidの実機で、共有機能（Web Share API）が動くかを試す。
9. **イラストの見積もり**: ココナラ・SKIMA・クラウドワークスで3〜5人に見積もりを頼む。
10. **利用規約**: e-Stat、こども家庭庁、厚労省、総務省、東京都オープンデータ、子育て支援制度レジストリの規約を読む。

## 12. 調査の限界

- 使えたのはWebSearchだけで、WebFetchは使えませんでした。PDFや統計表の中身（別紙3の列、e-Statの表、保育料表など）は、開いて確かめていないものが多くあります。
- 検索は米国リージョンの検索エンジンで行ったため、Google日本の順位やAI概要の出方とは一致しません。
- ASPの単価は二次情報が多く、掲載時期もばらばらです。申込率、承認率（注文住宅以外）、流入の内訳は仮置きです。
- 看板の主役となる都県境の保育料の差は、まだ検証していません。
- 令和8年度の移住支援金の実施自治体一覧と、国の共通要件は確かめられていません。
- 2026年の制度変更（横浜市・川崎市・広島市の医療費助成など）は、二次情報を含みます。
- 古い数字があります（水道料金は平成31年版、国保の地域差は2019年の記事）。
- 「専用ツールがない」というのは、3種類の検索で見つからなかったという意味にすぎません。
- 熊本地震は、見出しを見ただけで、内容は確認していません。
