# 試作のレビューと修正の記録

試作を作ったあと、互いの結論を知らない4人のレビュー担当に、別々の観点で見てもらいました。直したものと、まだ残っているものを記録します。

## 1. 税制・制度の正しさ

| 指摘 | 直したこと |
|---|---|
| 倍率が「約4倍」「約4.2倍」「3.6倍」と3通り出ていた | 見出しは入力に連動する計算値（例：3.6倍）にした。本文で「固定資産税は約4.2倍、都市計画税は2.1倍、合わせて約3.6倍（200㎡以下の土地）」と内訳を書いた |
| 「相続から3年目の12月31日」は誤り | 「相続から3年を過ぎた年の12月31日」に直し、「2024年3月に相続→2027年12月31日まで」の例を足した |
| 3,000万円控除は売った人ごとに使えるのに、家全体で1回しか引いていなかった | 「家と土地を相続した人数」を入力にし、持分ごとに控除を引くようにした（3人以上は1人2,000万円） |
| 控除の要件が築年と1億円だけだった | 計算の前提ページに主な要件を全部書き、明細には「控除を使えた場合」と「使えなければ◯万円」を並べた。使えない理由（築年・1億円超・期限切れ）も出し分けた |
| 800万円以下の仲介手数料を一律33万円で見積もっていた | 通常の上限で計算し、「800万円以下は事前の説明と合意があれば最大33万円」と注記した |
| 「負担調整措置で数年かけて上がる」は当てはまらないことが多い | 「通常は翌年度にまとめて上がる。負担調整措置は2026年度まで」に直した |
| 勧告の説明（1月1日までに手当て）が不正確 | 「1月1日の時点で勧告を受けたままだと、その年度は特例が外れる。勧告の撤回が必要」に直した。勧告がなくても特例が外れる場合（総務省の2015年通知）も足した |
| 1月1日の例が分かりにくい | 「2025年12月に解体→2026年度から、2026年1月2日に解体→2027年度から」と年を入れた |
| 出典の一部が民間サイトだった | 国税庁タックスアンサー、地方税法（e-Gov）などの一次資料に替えた |

## 2. 計算のバグ

| 指摘 | 直したこと |
|---|---|
| 1981年1〜5月築を入力する手段がなく、控除と補助金から外れていた | 1981年を入れたときだけ「5月以前／6月以降」を選ぶ欄を出す |
| 逆転の年を「初めて安くなった年」で決めていて、途中で逆戻りする場合を見ていなかった | 「その年から最後までずっと更地が安い」年にし、逆戻りや同額の場合の結論文を足した |
| 解体後の減免を1年目から数えていた | 更地として課税される2年目から数える |
| 補助金の上限が未設定だと0円、補助率0だと100%になっていた | 未設定は「上限なし」「補助率100%」として扱い、0〜100%に収めた |
| 地価を空欄にすると0円で計算していた | 空欄なら市の値に戻す。全角数字とカンマも受け付ける |
| 課税標準の端数で免税点の判定がずれた | 課税標準を千円未満切り捨てにしてから判定する |
| 全部0のときにグラフが壊れ、10年目の逆転ラベルが切れていた | グラフの上限を0より大きくし、端のラベルは右寄せにした |

## 3. デザイン

| 指摘 | 直したこと |
|---|---|
| ヒーローの家の絵が汎用のクリップアートで、題材らしさが弱い | 入力に連動する「課税明細書（見本）」に置き換えた。手元の明細のどこ（地積・価格）を見ればいいかが分かる |
| スマホで隠すはずの絵が出ていた | 見本はスマホでは出さず、計算ツールを最初の画面に入れた |
| 節の入り方が全部「見出し＋説明段落」の同じ型 | 税の節は数字を先に、市の比較は表の説明に、年表は日付を大きく縞なしに、市の数字は出典つきの表に、と節ごとに変えた |
| 広告が同じ形のカード2枚 | 「一括査定（仲介）と買取」の比較表1枚にまとめ、ボタンを表の下に置いた |
| 市の比較表がスマホで比べられない | スマホでは市ごとの縦積みにした |
| 明細の「なし」が多くて数字が埋もれる | 「—」にして薄くした |

## 4. SEO・広告表記

| 指摘 | 直したこと |
|---|---|
| canonical・OGP・構造化データ・sitemap・robots がない | すべて出力するようにした（ドメインは仮。`SITE.origin`） |
| 300市に広げると、データの薄い市が量産ページになる | 計算に使う3項目が確認できていない市は自動で noindex にし、ページにもその旨を表示した。市ごとの手書きの解説を足した |
| 広告の開示が売る節の最後に薄い色であった | 見出しの直後に、本文と同じ色・太字・「広告」ラベルで出した |
| プライバシーにASPのCookieとGoogle Fontsの記載がない | 足した |
| 明細を見た人が査定に進む導線がない | 明細の下に「売却額は推定です。実際の査定額を入れると比べ方が変わります → 値段の調べ方」を置いた |
| 広告ではない選択肢がない | 市の空き家バンクと相談窓口を、広告と同じ節に書いた |

## まだ残っていること

- 運営者情報・体験談・連絡先・広告タグは〔〕のまま（本人が書く必要がある）。ビルドの最後に残っているページを表示する。
- 写真がない。運営者が撮った空き家の写真に差し替えると、いちばん効く一次情報になる。
- 宇都宮市（都市計画税・地価・補助金の上限）と加賀市（地価）の数字が未確認。今は noindex。
- 制度の解説ページ（特例・管理不全空家・3,000万円控除など）はまだない。`docs/03_site-plan.md` の「最初の50ページ」に入れてある。
- 県のページ（パンくずの中間）と、年次の集計ページはまだない。
