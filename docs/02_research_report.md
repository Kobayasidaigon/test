# ジャンル選定の調査レポート

調査日: 2026年10月31日〜11月1日

## 調査の流れ

1. **条件の見直し**：4つの観点（2024〜2026年の検索環境／収益の仕組み／条件の妥当性／運営・法務・AIっぽさ）を並行して検討し、1つの条件セットにまとめた。詳細は [01_criteria.md](01_criteria.md)。
2. **候補出し**：5つの起点（公的データ／高単価案件／個人の成功例／固有名詞の組み合わせ／地域×制度）から44件を出し、12件と比較用2件（車種×維持費、ハウスメーカー×坪単価）に絞った。
3. **1回目の検証**：14件それぞれを根拠集め→反証の順で検証した。ただし途中でWeb検索の上限（1ターン200回）に達し、ほとんどの候補が検索なしの暫定評価になった。
4. **再検証**：上位7件について、1件あたり根拠集めに検索12回・反証に8回を割り当てて検証し直した（計140回）。**このレポートの結論は再検証の結果にもとづく。**

## 調査の限界

- 使えたのはWeb検索だけ（米国リージョンの検索エンジン）。検索上位の顔ぶれはGoogle日本の順位そのものではなく、近似。
- A8.netなどの管理画面は見られないため、報酬単価・確定率・否認条件は公開情報から拾える範囲に限られる。
- 検索数（キーワードのボリューム）は取れていない。

## 結論

- **推奨（条件付き）: K01**。市区町村×空き家の解体補助金を入口にした「解体するか・売るか・持つか」の判断サイト。K04の土地価格は、判定ツールの入力として組み込む。
- **次点1: K02**（市区町村×給湯器・断熱窓などの補助金→リフォーム見積もり）。
- **次点2: K04**（市区町村×土地価格）。単独のサイトにはせず、K01の部品として使う前提。
- **選定条件をそのまま満たす候補はなかった。**
  - 再検証した7候補・計52本の上位構成（米国リージョンでの近似）で、個人・小規模サイトが2件以上入ったクエリは0本。
  - 個人らしきサイトが1件でも入ったのは、K07の「世田谷区 保育士 家賃補助」の1本だけ。
  - 7候補すべてが、必須条件のC6で落ちた。
- **K01を推す理由は2つ。成立させるために緩める条件が最も小さく、根拠も最も確か。**
  - C6が1点になる条件は「企業メディアと比較・予約サイトが上位10件中8件以上を占めるクエリが過半数」。K01の9本でこれに当たるのは1〜2本だけ。組み合わせ型のクエリの上位は、自治体公式と補助金ポータル。
  - 文言どおりならC6は2点になり、必須条件をすべて満たす（加重点44.4）。ただし趣旨（個人が入る余地）からは1点に近い。
  - 単価の根拠は、全候補で最も確か。A8の高単価ランキングで、訳あり不動産専門買取「ワケガイ」（株式会社ネクスウィル）の新規査定申込30,000円を特定した。
- **成立させるために緩める条件**
  - C6: 「上位に個人・小規模サイトがいる」を「企業・比較サイトの独占ではない（上位の大半は自治体公式）」に緩める。日本のブラウザで確かめることが前提。
  - C4: 「広告主3社・ASP2社」を「確定単価1万円以上の案件1社を管理画面で確認し、6ヶ月以内に2社目を確保」に緩める。採点上は2点で必須条件を通るが、1社依存のリスクを受け入れることになる。
  - 目標: C1は3点で通る。ただし18ヶ月で月10万円に届くのは、判定ツールで申込率を上げられた場合に限る（下の逆算）。
- **K02はK01と案件も上位構成も別なので、K01が案件の確認で落ちたときの代わりになる。**
  - 必須条件で落ちたのがC6だけの、もう1つの候補（39.6点）。
  - ただし収益型のクエリは、ミツモアが10件中10件を占める。文言どおりに読んでも、7本中3〜4本が独占で、1点との境界にある。
  - C1〜C4はすべて2点で、余裕がない。
  - 成立させるには、C6を情報型のクエリだけで判定する必要がある（収益型は狙わない）。2027年度の国の事業が続くかも確かめる。
- **K04は、単独では成立しない。**
  - 7本すべてで大手が占め、ダイヤモンド不動産研究所は大字単位のAI予測ページまで持っている。
  - K01で特定したワケガイを当てれば、C1とC4は戻りうる（推定）。それでもC6は戻らない。
  - K01と案件も読者も重なるので、K01の代わりにはならない。判定ツールで土地の値段を入れる部品として残す。
- **月10万円の見込み（推定）**
  - 読者の意図（解体したい）と案件（訳あり物件を売りたい人向け）がずれるので、申込率を0.5%に下げた。この場合、必要PVは約8.3万（1回目は約4.2万）。
  - 18ヶ月目に届くのは、判定ツールで広告クリック率2%・申込率1%前後まで上げられた場合だけ（必要PVは約2.1万）。
- **進める前に、3つの確認を通すこと**: ASPの管理画面での案件確認、日本のブラウザでの上位構成、キーワードプランナーでの検索数。
  - 案件の確認で落ちたら、K02の確認に移る。
  - 上位構成で落ちたら、K01・K02・K04は同じ理由で全部落ちる。その場合は候補を作り直す。
- **「AIで作ったとまるわかりなサイトは避けたい」という要望との関係**
  - 生活ガイド.comのように、数百の自治体のページを同じ型で量産する作りは、この要望とぶつかる。
  - 推奨案は、自治体ページを30ページ以内から始め、判定ツール・担当課への確認記録・実例を中心にする。

## 候補ごとの再検証結果

### K01 市区町村×空き家（推奨・条件付き）
加重点は50.0（調査担当）から**42.4**（反証後）になった。必須条件で落ちたのはC6（暫定1点）だけ。

- **案件（C1・C4）**
  - A8の高単価ランキングで、30,000円の案件がワケガイ（ネクスウィル）の新規査定申込（無料申込型）だと特定した。同じランキングに、リショップナビの新規見積申込10,000円もある。 https://support.a8.net/as/HintOfProgram/ranking/highprice.php
  - ただし「ワケガイ」「ネクスウィル」の名前で独立に検索しても、案件の今の状態を示すページは出なかった。否認条件、対象エリア、確定率は未確認。
  - 解体の一括見積もり（クラッソーネ、解体の窓口）は、アフィリエイト案件があるかを確認できなかった。
    - クラッソーネは、成約時に工事会社が工事金額の10%を払う仕組み（2020年の報道 https://www.bcnretail.com/market/detail/20200330_164210.html ）。
    - クラッソーネは110自治体と連携している（2025年3月時点 https://newswitch.jp/p/23534 ）。
    - 川崎市は、解体一括見積サービスと連携している（ https://www.city.kawasaki.jp/500/cmsfiles/contents/0000145/145165/kaitai_bosyu_youryou.pdf ）。
    - 神戸市は、公式サイトに見積シミュレーターを置いている（ https://www.city.kobe.lg.jp/a92551/business/todokede/jutakutoshikyoku/building/work/kaitaimitsumori_simulator.html ）。
    - つまり、補助金を調べる読者の自然な次の行動（解体の見積もり）は、自治体自身が受け止めている。
  - 訳あり買取の代わりの広告主として、AlbaLink（2025年に東証グロース上場）を記録した。アフィリエイト案件があるかは未確認（ https://www.kenbiya.com/kaisha/albalink-hiroshima/ ）。
  - C1は3点。申込率0.5%での必要PV約8.3万は4点帯で、季節の谷で1点下げた。
  - C4は2点。1社依存で、しかもその1社の今の状態が未確認のため。
- **上位構成（C6）**: 9本を調べ、個人・小規模サイトは0件だった。
  - 組み合わせ型の上位は、自治体公式と法人のポータル。
    - 生活ガイド.comは、市区町村コードごとの空き家解体ページを量産している（ https://www.seikatsu-guide.com/keyword/1400/28/28100/ ）。
    - 補助金ポータル（ https://hojyokin-portal.jp/subsidies/66697 ）も、同じ型で上位にいる。
  - 収益型の上位は、企業メディア・仲介大手・大手メディア・ミツモア（ https://e-estate.jp/media/?p=9557 、 https://www.rehouse.co.jp/relifemode/column/at/at_0080/ 、 https://bunshun.jp/articles/-/63606 、 https://meetsmore.com/services/house-demolition/osaka ）。
  - 「ブログ 体験記 申請してみた」を入れても、出たのは静岡新聞と、自治体・企業メディアだけだった（ https://www.at-s.com/life/article/ats/1957176.html ）。
  - 古いページも上位にあるが、どれも自治体公式。例は、鳴門市のH30版（ https://www.city.naruto.tokushima.jp/_files/00174701/gaiyou_h30.pdf ）と、箕輪町の2022年版。
- **データ（C2・C3）**
  - 補助金の軸には、自治体ごとの固有の値が多い。
    - 静岡市: 2026〜2027年度に限った制度。補助率1/2、上限100万円、法人は対象外、木造は簡易耐震診断7点以下（ https://www.city.shizuoka.lg.jp/documents/58302/tirasi.pdf ）。
    - 鳴門市（R7）: 不良度100点以上、上限60万円／80万円、補助率2/3／4/5、施工は市内業者に限る（ https://www.city.naruto.tokushima.jp/_files/00618441/gaiyou_r7_.pdf ）。
    - 箕輪町と千曲市（ https://www.city.chikuma.lg.jp/material/files/group/47/q-a-2.pdf ）でも確かめた。
  - 一方、「宇治市 解体費用 相場」では市に固有のデータが出なかった。解体費用の軸は、全国の坪単価を差し替えるだけになる。
  - C2は3点。確かめた自治体は約10で、採点基準の15組に届いていない。
  - 神戸市は、2026年度に対象の築年を「1986/12/31以前」に広げた（令和7年度は1981/5/31以前）。受付は2026/3/2〜2027/1/12で、予算がなくなり次第終わる（ https://www.city.kobe.lg.jp/documents/25370/r8tebiki.pdf 、 https://www.city.kobe.lg.jp/documents/25370/r7_youkou.pdf ）。
  - C3は2点。毎年の改定と年度途中の受付終了を、手作業で追う必要があるため。
- **法務（C10）**: 2点。
  - 国民生活センターは、業者に自宅を売る場合はクーリング・オフができず、強引な勧誘で安く売らされたトラブルがあると注意している（2021年 https://www.kokusen.go.jp/news/data/n-20210624_1.html ）。
  - リースバックの強引な勧誘にも、注意喚起がある（2025年 https://www.zentaku.or.jp/cms/wp-content/uploads/2025/05/報道発表資料_強引に勧められる住宅のリースバック契約にご注意！.pdf ）。
  - 紹介料を受け取ること自体は違法ではない。ただし、反復・継続して取引に関わると、宅建業法の無免許営業にあたるリスクがある（解説 https://atsoho.com/blog/real-estate-referral-fee-legality ）。
- **成功例（C9）**: 0点。
  - 空き家ジャンルで、個人の成功例は見つからなかった。
  - バトンズに、新築戸建て情報ブログで月平均14万円という例がある（2025年。隣接ジャンルで、PVは未確認。 https://batonz.jp/sell_cases/66955 または https://batonz.jp/sell_cases/71132 ）。同じジャンルの根拠にはならない。

### K02 市区町村×給湯器・断熱窓などの補助金（次点1）
加重点は40.6から**39.6**になった。必須条件で落ちたのはC6だけ。

- **上位構成（C6）**: 7本を調べ、個人・小規模サイトは0件だった。
  - 収益型の「エコキュート 交換 見積もり 補助金 安い業者 おすすめ」は、ミツモアの市区町村別ページが10件中10件を占めた（ https://meetsmore.com/services/water-heater-exchange/tokyo/oume ）。量産したい組み合わせを、ミツモアがすでに持っている。
  - 給湯器交換の口コミ系は、みん評と広告主自身のページだった（交換できるくん https://www.sunrefre.jp/voice/?p=41074 、 https://minhyo.jp/choice/gas-kyuutouki ）。
  - 文言どおりの1点の条件に当たるのは7本中3〜4本で、境界にある。
- **案件（C1・C4）**
  - A8のランキングに、10,000円のリフォーム一括見積がある。広告主については判断が割れた。K01の調査担当は「リショップナビ」と確認したが、K02の反証担当は広告主名を確定できなかった。
  - ヌリカエ、外壁塗装の窓口、タウンライフ、キンライサーの報酬は、計8回の検索で1件も出なかった。
  - C1・C4ともに2点。
- **制度**
  - 国の給湯省エネ2026事業は、予算570億円。交付申請は遅くとも2026/12/31まで（民間の解説 https://www.shigyo.co.jp/search_post/housing-subsidy/housing_energy_saving2026/breaking_news/ ）。
  - 2027年度の事業は未確認。決まるのは今日（2026/11/1）より後と見られる（推定）。
- **補助の条件と送客の食い違い**
  - 川口市の補助は、市内の施工業者と契約したうえで、着工前に申請することが条件（ https://www.city.kawaguchi.lg.jp/material/files/group/117/R8youkou.pdf ）。一括見積から紹介された市外の業者では、対象外になりうる。
  - 横浜市と所沢市には、個人向けの設備ごとの独自補助が見当たらない。
- **法務（C10）**: 3点。
  - 給湯器の点検商法の相談が約3倍に増え、契約した人の7割以上が70歳以上（ https://www.kokusen.go.jp/news/data/n-20240221_1.html ）。
  - 悪質リフォームの摘発は、2021年の43件から2025年には83件に増えた（ https://www.sakigake.jp/news/article/20260723AK0004/ ）。
- **強み**: 自治体の担当課への確認記録を、費用をかけずに入れられる。C7は3点で、全候補で最も高い。

- **扱い**: 単独のサイトにはしない。K01の判定ツールで、土地の値段を入れる部品として残す。
