# 追加で調べる4項目のプロンプト（2026年11月2日）

どのプロンプトも、最初に「共通の前提」を付けて使う。1回に渡す市区町村は10〜20（人口の多い順の一覧 `munis_by_pop.json` の範囲で指定）。

---

## 共通の前提

```
「住む街ガチャ」（https://sumugacha.com。家族の条件を入れると、引っ越し先の街で家計が年いくら変わるかを計算するサイト）のために、全国の市区町村のデータを、その市区町村の公式サイトから集める。返答は日本語。

- 対象の市区町村: 人口の多い順の一覧（munis_by_pop.json。各要素に code・pref・name・url）の ◯番目〜◯番目。
- 時点は令和8年度（2026年度）。今年度の情報がなければ最新の年度を書き、その年度をはっきり書く。
- 出典は市区町村・都道府県・国の公式のページや資料（PDF・例規集を含む）。民間のまとめサイトは使わない。どうしても公式で確かめられないときだけ参考にし、確からしさを「推定」にする。
- 推測で埋めない。分からない項目は null にし、「分からない」は「なし」や0円とは書き分ける。
- 値ごとに、時点・出典（ラベルとURL）・確からしさ（確認済＝公式の今年度の資料で読んだ／推定／仮置き）を付ける。
- サイトへのアクセスは、同じサイトに0.5秒以上あけて1つずつ。ボット対策をすり抜ける細工（ヘッダーの偽装など）はしない。開けないサイトは、試したことを tried に書いて次へ進む。
- 1つの市区町村に使う時間の目安は5分。
- 結果は、市区町村ごとに1つの JSON ファイル（下の形）にする。
```

## 1. 国民健康保険料

```
# 調べること: 国民健康保険料（税）の令和8年度の計算方法
自営業・フリーランスの家族が、街によって年にいくら国保料が違うかを計算するために使う。

各市区町村の「国民健康保険料（税）の計算方法・税率」のページを読み、次を取る。
- 名前: 「保険料」か「保険税」か
- 区分ごとの率と額（医療分・後期高齢者支援金分・介護分（40〜64歳）・子ども・子育て支援金分（令和8年度から））:
  - 所得割の率（%）
  - 均等割（1人あたりの年額、円）
  - 平等割（1世帯あたりの年額、円。ない街は null）
  - 資産割（ある街だけ）
  - 賦課限度額（円）
- 未就学児の均等割の軽減（国の制度で5割）以外に、街独自の子どもの軽減があればその中身
- 産前産後の免除など、子育て世帯に関係する独自の減免

書くファイル: data/kokuho/raw/<code>.json
{
  "code": "", "pref": "", "name": "",
  "status": "ok" | "partial" | "not_found",
  "fiscal_year": "令和8年度",
  "kind": "保険料" | "保険税",
  "parts": {
    "iryo":   { "shotoku_rate": %, "kintou": 円, "byoudou": 円|null, "shisan_rate": %|null, "limit": 円 },
    "shien":  { 同じ形 },     // 後期高齢者支援金分
    "kaigo":  { 同じ形 },     // 介護分（40〜64歳）
    "kodomo": { 同じ形 }|null // 子ども・子育て支援金分
  },
  "child_reduction": "街独自の子どもの軽減（なければ null）",
  "sources": [ { "label": "", "url": "" } ],
  "confidence": "確認済" | "推定" | "仮置き",
  "tried": [], "notes": "", "read_at": "2026-11-0X"
}
- 率は数字だけ（例: 7.45）。額は円の数字だけ。
- 所得割の基準は「旧ただし書き所得（総所得金額等 − 基礎控除43万円）」がふつう。違う街は notes に書く。
```

## 2. 水道料金

```
# 調べること: 家庭用の水道料金（令和8年度）
同じ量を使ったとき、街によって年にいくら水道代が違うかを計算するために使う。

まず、総務省「地方公営企業年鑑」の最新版の水道事業の表（事業体ごとの家庭用料金。口径13mm・20mm、月10㎥・20㎥の料金）を取り、市区町村コードと事業体を対応させる。広域の企業団・用水供給の街は、どの事業体の料金がその街に当たるかを書く。
そのうえで、年鑑の年度より後に料金を改定した街（令和7・8年度の改定）は、市区町村や水道局の公式ページで今の料金表を確かめて上書きする。
下水道使用料も、家計の目安として取れれば取る（同じく月20㎥）。

書くファイル: data/water/raw/<code>.json
{
  "code": "", "pref": "", "name": "",
  "status": "ok" | "partial" | "not_found",
  "operator": "水道事業体の名前（例: 〇〇市上下水道局、〇〇広域水道企業団）",
  "as_of": "料金の時点（例: 令和8年4月1日）",
  "water": { "d13_10m3": 円, "d20_20m3": 円, "billing": "月ごと" | "2か月ごと", "tax_included": true },
  "sewer": { "d20_20m3": 円 } | null,
  "revised": "最近の改定（例: 令和8年4月に平均15%値上げ）" | null,
  "sources": [], "confidence": "", "tried": [], "notes": "", "read_at": ""
}
- 料金は1か月あたり・消費税込みにそろえる（2か月ごとの請求なら半分にし、そう書く）。
- 簡易水道や地区によって料金が違う街は、いちばん人口の多い地区の料金を入れ、ほかは notes に書く。
```

## 3. 住宅の補助

```
# 調べること: 子育て世帯・移住者向けの住宅の補助（令和8年度）
引っ越す家族が受けられる住宅のお金を、一度きりのお金（または毎月の補助）として見せるために使う。

各市区町村の「住宅取得の補助」「家賃補助」「移住・定住の支援」「空き家バンクの改修補助」「三世代同居・近居の補助」のページを読み、子育て世帯か転入者が使える制度を全部取る。
- 制度の名前、種類（住宅の新築・購入／中古の購入・改修／家賃の補助／空き家の改修／同居・近居）
- 金額（上限額、子どもの数や転入で加算されるならその額、家賃補助なら月額と期間）
- 主な条件（転入者だけか、子どもの年齢、世帯の年齢、所得、市内業者の利用、住み続ける年数、受付期間・予算の上限）
- 令和8年度に受け付けているか（予算に達して終了していないか）

書くファイル: data/housing/raw/<code>.json
{
  "code": "", "pref": "", "name": "",
  "status": "ok" | "none" | "partial" | "not_found",   // none=公式で調べて、対象の制度がないと分かった
  "programs": [
    {
      "name": "",
      "kind": "new_build" | "purchase_used" | "renovation" | "rent" | "akiya" | "multigenerational" | "other",
      "max_amount": 円 | null,              // 一度きりの上限
      "child_addition": "子ども1人あたり◯円 など" | null,
      "monthly": 円 | null, "months": 月数 | null,  // 家賃補助
      "for_movers_only": true | false | null,
      "conditions": "主な条件を短く",
      "open_fy2026": true | false | null,    // 令和8年度に受け付けているか
      "source": { "label": "", "url": "" },
      "confidence": ""
    }
  ],
  "tried": [], "notes": "", "read_at": ""
}
- 都道府県の制度は、市区町村のページに書いてあるときだけ入れ、name に都道府県の制度と分かるように書く。
- 国の制度（子育てグリーン住宅支援事業など、全国どこでも同じもの）は入れない。
```

## 4. 独自の祝い金・手当

```
# 調べること: 市区町村独自の、子どもへのお祝い金と手当（令和8年度）
児童手当など国の制度とは別に、街が独自に出しているお金を集める。

各市区町村の「子育て支援の一覧」「出産・子育ての手当」「子育てガイドブック（令和8年度版）」を読み、次を取る。
- 一度きりのお金: 出産祝い金、入学祝い金（小・中）、誕生日の祝い金、第3子以降のお祝い、転入した子育て世帯への給付 など
- 毎月・毎年のお金: 独自の子育て手当、第3子以降の手当、在宅育児手当、高校生への給付 など
- 現金に近いもの（金額が分かるものだけ）: 商品券、おむつ・ミルクの配布（年額の目安）
それぞれ、金額、何人目の子が対象か、子の年齢、所得の条件、住んでいる年数などの条件。

書くファイル: data/benefits/raw/<code>.json
{
  "code": "", "pref": "", "name": "",
  "status": "ok" | "none" | "partial" | "not_found",   // none=公式で調べて、独自の制度がないと分かった
  "one_time": [
    { "label": "", "amount": 円 | null, "by_order": { "1": 円, "2": 円, "3+": 円 } | null,
      "timing": "出生時／小学校入学時／など", "conditions": "", "form": "現金" | "商品券" | "物品",
      "source": { "label": "", "url": "" }, "confidence": "" }
  ],
  "recurring": [
    { "label": "", "per_child_yearly": 円 | null, "monthly": 円 | null, "from_age": 歳 | null, "to_age": 歳 | null,
      "by_order": "何人目から" | null, "conditions": "", "form": "現金" | "商品券" | "物品",
      "source": {}, "confidence": "" }
  ],
  "tried": [], "notes": "", "read_at": ""
}
- 国の制度（児童手当、出産・子育て応援給付金〈妊婦のための支援給付〉など全国共通のもの）と、東京都の018サポートのような都道府県の制度は入れない（別に持っている）。
- 保育料の調べ（data/fees/raw/<code>.json の cash・one_time）にすでに書いてあるものは、公式で確かめてから写してよい。
```

## 使い方のメモ

- 1回目は、人口の多い順で10市区町村だけで試し、取れ方を見てから広げる。
- 1組ごとに、別の担当が3つを抜き取りで読み直す（保育料・給食と同じやり方）。
- 水道料金は、地方公営企業年鑑を先に取り込めば、全国分の大半が1回でそろう。市区町村ごとに読むのは、改定があった街だけでよい。
