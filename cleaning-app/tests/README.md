# 試験

```
cd cleaning-app
npm install
bash tests/runv.sh 46          # 番号を並べれば続けて走る
```

結果は `tests/out/r_<番号>.out`、画面の写真は `tests/out/*.png`。
`tests/out/` は git に入れない。

## 大事なこと

**試験はここに置く。作業用の一時置き場に置かない。**

2026-10-13、35本・653件の試験を一時置き場にだけ置いていて、
コンテナが作り直されたときに全部消えた。リポジトリに入っていたのは
アプリ本体だけだったので、アプリは無事だったが安全網は消えた。

消えたぶんのうち、やり取りに残っていたものは入れ直す。
それ以前のもの（verify2〜42）は復元できない。

## 走らせ方の注意

`runv.sh` は「残っているサーバーを全部落とす」ところから始まる。
`ps` の出力に `server.js` が含まれるプロセスを落とすので、
**このスクリプトを呼ぶコマンド行に `server.js` という文字を入れないこと。**
自分を呼んだシェルごと落ちる（3回やった）。
