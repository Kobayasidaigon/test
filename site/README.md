# 空き家の算段（サイトの骨組み）

相続した空き家を「解体してから売る／古家付きのまま売る／業者の買取に出す／持ち続ける」の4択で比べるサイトです。市町村の解体補助金と固定資産税の数字を使います。

- 依存パッケージはありません（Node.js 20 以上だけで動きます）。
- データ（`data/`）とひな形（`src/pages/`）から、静的なHTMLを `dist/` に書き出します。
- 計算の式は `src/assets/calc.js` の1か所にまとめています。トップの例と判定ツールで同じ式を使います。

## 使い方

```sh
cd site
node build.mjs            # dist/ に書き出す
node serve.mjs            # http://localhost:4321 で確認する
node build.mjs --preview  # ファイルを直接開いて確認する用（リンクに index.html が付く）
node check.mjs            # 公開前のチェック（データの欠け、出典のない数字、ページ間の重複率）
```

公開先は、`dist/` をそのまま置ける静的ホスティングならどこでも使えます（Cloudflare Pages、Netlify、GitHub Pages など）。ビルドコマンドは `node build.mjs`、公開するフォルダは `dist` です。

## フォルダ

| 場所 | 中身 |
| --- | --- |
| `src/config.mjs` | サイト名、ドメイン、運営者情報、広告の方針 |
| `data/cities/*.json` | 市町村ごとの補助制度・都市計画税率・空き家率・出典（1市町村1ファイル） |
| `data/params.json` | 税の特例の割合、税率、解体費の単価の幅と、その出典 |
| `data/prefs.json` | 都道府県 |
| `data/offers.json` | 判定結果ごとの広告の枠。`url` が空なら表示しない |
| `data/log.json` | 担当課への確認記録と更新履歴 |
| `src/pages/` | ページのひな形 |
| `src/assets/` | CSS、計算（calc.js）、表示（view.js）、判定ツール（tool.js） |

## 市町村を追加する

1. `data/cities/` に `{市町村のローマ字}.json` を作る（既存のファイルを複製するのが早い）。
2. 要綱を読んで、上限額・補助率・要件・受付期間・契約前申請の要否・担当課・出典URLを入れる。確かめられない項目は `null` にして、`unverified` に書く。
3. `checked_at` に確かめた日を入れる。
4. 担当課に電話で確かめたら、`data/log.json` に記録を足す（`city_slug` を入れると、その市町村のページに出る）。
5. `node check.mjs` で、公開条件を満たしているか確かめる。

**公開条件**（量産ポータルと同じ「上限額・補助率・期間の表」だけのページにしないため）

- 要綱にもとづく固有の項目が5つ以上ある
- 申請でつまずく点が書いてある
- 出典URLがある
- 担当課への確認記録が1件以上ある（公開前に電話で確認する）

条件を満たさない市町村は、ファイルに `"publish": false` を入れると、ページを作らずに済みます。

## 公開前にやること

調査レポート（`../docs/02_research_report.md`）の「立ち上げ前に人が確かめること」と同じ順番です。

1. **ASPの管理画面で案件を確かめる**：A8.net のワケガイ（訳あり不動産買取、新規査定申込30,000円とランキングに掲載）の提携可否・成果条件・否認条件・確定率。もしも・afb・バリューコマース・アクセストレードで、空き家や地方の物件を受け付ける査定・買取の案件。決まったら `data/offers.json` の `url` と `advertiser` を埋める。
2. **日本のブラウザで検索上位を確かめる**：シークレットウィンドウで「{市} 空き家 解体 補助金」を10本、判断系の言葉を5本。上位が企業・比較サイトで埋まっているなら、進め方を見直す。
3. **キーワードプランナーで検索数を確かめる**。
4. **運営者情報を書く**：`src/config.mjs` の `operator`。空き家との関わりを自分の言葉で。実家や現地の写真があれば `src/assets/` に置いて使う（このサイトでいちばん「AIっぽさ」を消せる素材です）。
5. **ドメインを決める**：`src/config.mjs` の `baseUrl`。サイト名の商標とドメインの空きも確かめる。
6. **扱う県を決めて、担当課に電話で確かめる**：月1回見て回れる数（30市町村くらい）まで。
7. **税の割合と解体費の単価を、一次資料で確かめ直す**：`data/params.json` の `sources`。

## デザインの決まりごと

- 書体は BIZ UDPゴシック（自治体の文書でも使われるユニバーサルデザイン書体）の1つだけ。
- 色は、地の色・文字の色・面の緑・朱の4つ。朱はボタンと、判定ツールの扉の絵にだけ使う。
- グラデーション、影、細い罫線、アイコン付きのカードの並び、絵文字、小さな英字のラベルは使わない。区切りは文字の大きさと面の色で作る。
- 数字には出典と確認日をつける。確かめられない数字は載せない。
