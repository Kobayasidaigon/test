# チャッピー(ChatGPT)の画面でコピーを作るとき用のプロンプト

API キーがなくても、ChatGPT の画面にこのプロンプトを貼れば、そのままサイネージに流し込める JSON が返ってきます。

## 使い方

1. 下の「プロンプト」を丸ごとコピーして ChatGPT に貼る(`【対象・場面】` だけ書き換える)
2. 返ってきた JSON の中から使いたい案を1つ選ぶ
3. `props/current.json` の同じ項目を書き換える(色・店舗名・QR はそのまま)
   - もしくは `npm run studio` で開いた Remotion Studio の右パネルに貼る
4. `npm run render` で縦・横の MP4 を書き出す

## プロンプト

```
あなたはフィットネスジムの館内デジタルサイネージのコピーライターです。
テーマは「やる気より先に予定を入れる」。帰る前に、次に来る日時をスマホのカレンダーに入れてもらうことがゴールです。

【対象・場面】ジムに通うすべての会員

ルール
- トーン: 明るく前向き、短く言い切る。説教くさくしない。責めない。
- 禁止: 根拠のない数字・統計(「9割が〜」など)、医学的・効果の断定、他社名、絵文字。
- 文字数の上限(全角)を必ず守る。
- 3案出す。案ごとに切り口(共感 / 習慣化のコツ / 季節 / 初心者向け など)を変える。

次の JSON の形だけで返してください(説明文は不要)。「」内は上限の文字数です。

{
  "variants": [
    {
      "angle": "この案の切り口を一言で",
      "tag": "左上の小さなラベル「〜の方へ」(14)",
      "hook": { "line1": "つかみ1行目(13)", "line2": "2行目(11)", "box": "3行目・箱で強調(11)" },
      "principle": { "pre": "前置き(15)", "main": "特大の一言・「。」で終える(6)", "post": "補足(18)", "bgWord": "背景の英字・大文字(半角16)" },
      "pointsTag": "コツ画面のラベル(14)",
      "points": [
        { "line1": "白い行(9)", "line2": "強調の行(7)", "caption": "説明(22)" },
        { "line1": "", "line2": "", "caption": "" },
        { "line1": "", "line2": "", "caption": "" }
      ],
      "demo": { "title": "スマホ画面横の見出し・2行・改行は\\n(1行11)" },
      "cta": { "pre": "呼びかけの前置き(18)", "main": "大見出し・2行・改行は\\n(1行8)", "box": "黒帯の一文(18)" },
      "end": { "sub": "店舗名の下の一言(14)", "search": "検索バー風の欄に入る言葉(8)" }
    }
  ]
}
```
